1.1.3. 동적 쿼리 실행 시 입력값 검증
정적 쿼리를 사용할 수 없는 경우에는 반드시 입력값 검증으로 쿼리 조작 문자열 포함 여부를 확인한 후 사용해야 한
다. 해당 검증 로직은 공통 모듈로 개발하여 검증 규칙이 일관되게 적용될 수 있도록 한다.
st.creatStatement(“select id from table where id=’”+SQLFilter(id)+”’”);
