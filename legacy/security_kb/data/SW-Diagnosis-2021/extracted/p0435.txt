하고 사용한다.

1: String url = reuqest.getParamter("url");
2: //null값을 가지는 참조 변수를 사용할 경우, null 검사를 수행하고 사용한다.
3: if ( url != null || url.equals("") )

하게 되고, username은 null 값을 가지게 되어 널(Null) 포인터 역참조가 발생한다.
