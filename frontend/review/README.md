# 개발용 화면 확인

프론트 폴더에서 `npm run dev:review`를 실행하고 http://127.0.0.1:5190/dev/screens 를 연다.

현재 사용자 화면 17개를 실제 컴포넌트로 연다. 이전 흐름 시안은 별도 접힌 목록에 있다. 일반 개발 서버의 하단 `작업한 화면 보기`에서도 목록으로 진입한다.

상태를 고른 뒤 화면을 누르면 예시 자료가 초기화된다. API를 조회하는 화면에는 처리 중, 요청 실패, 만료를 적용한다. 자료 없음은 공고와 저장 자료 목록, 경험 확인에 적용한다. 공고 마감과 변경은 상세와 지원서에서 확인한다. 수정 후 이탈은 지원서 또는 경험을 수정하고 앱 안의 뒤로가기나 링크로 이동해 확인한다.

화면 아래의 이전 화면과 다음 화면으로 목록 순서대로 이동할 수 있다. 선택한 상태는 유지되며, 각 화면에 들어갈 때 예시 자료는 다시 초기화된다.

이 서버는 로컬 5190 포트에서만 실행한다. API 요청은 서버 메모리의 가상 자료로 처리하며 실제 백엔드로 전달하지 않는다. 알 수 없는 API는 실패한다. 실제 AI, OAuth, 음성 모델, 회원 저장, 운영자 인증의 성공을 검증하는 환경이 아니다. 서버를 종료하면 예시 변경은 사라진다. 이 서버 파일은 제품 번들에 포함하지 않는다.

일반 서버는 `npm run dev`로 실행한다. 실제 서버 연결 검증과 화면 검수는 구분해서 기록한다.
