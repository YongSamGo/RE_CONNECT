# 브라우저 화면 검증과 큰 글씨 모드

기준일: 2026-10-28. 자동 검사는 접근성 적합성이나 실제 기기 사용성의 판정이 아니다.

## 실행과 기준 이미지

`frontend/`에서 `npm ci --ignore-scripts`, `npx playwright install chromium`, `npm run test:browser`를 실행한다. CI의 Windows 2022 Chromium 잡도 같은 명령을 사용한다. 기준 PNG는 Windows에서 만든 것이므로 다른 운영체제의 글꼴·렌더링 결과와 직접 비교하지 않는다. 의도한 UI 변경의 경우 Windows에서 `npx playwright test --update-snapshots`를 실행하고 변경된 이미지를 사람이 검토한다. 자동 업데이트를 CI에서 실행하지 않는다.

320·390·768·1280 CSS px, 기본/큰 글씨에서 시작·안내·미리보기 입력·프로필·작성 연습·공고 지도와 검색·가상 공고 상세·내 정보를 확인한다. 검색과 상세는 테스트 전용 가상 응답이다. 홈과 안내의 전체 페이지 기준 이미지, 가로 넘침 및 주요 조작의 좌우 위치, 홈과 안내의 axe 규칙을 검사한다. 키보드로 전환 버튼에 접근하고 저장소 사용이 거절될 때 동작하는지도 확인한다. SVG 지도 세부 지역, 모든 오류·비동기 성공 상태, 텍스트가 내부 컨테이너에 가려지는 모든 경우를 포괄하는 검사는 아니다.

큰 글씨 설정은 `reconnect-large-text` 키에 on/off만 기록한다. 저장소가 차단되면 현재 방문에서만 동작한다. 글자 크기에 1.2배를 적용하며 페이지 전체를 확대하지 않는다. 지원 브라우저와 확대·기기의 조합은 별도 검증해야 한다.

## 이번 실행과 미확인

- Windows의 Playwright Chromium에서 브라우저 검사 10개 통과(8개 크기·모드 조합과 키보드·저장소 차단). 기준 이미지를 작성한 실행과 비교 실행을 구분한다.
- 빌드와 API 타입 확인 통과. 린트는 기존 작업 중인 `RegionSelectionMap.tsx`의 Fast Refresh 경고 3건 때문에 실패했다.
- App·접근성 기존 단위 테스트 46건 중 최초 실행에서 8건 실패했다. 현재 공고 UI와 이전 기대값 차이 및 저장소 쓰기 관련 실패를 확인했으며 초기 렌더의 불필요한 설정 쓰기를 제거했다. 해당 테스트 전체를 다시 통과했다고 주장하지 않는다.
- CI 원격 실행, 실제 Android/iPhone, 브라우저 200% 확대, 스크린리더, 실제 API 성공 상태와 시니어 사용자 검증은 미실행이다. 320px 뷰포트는 200% 확대나 실기기 검증이 아니다.
- 소개 영상이 아직 없어 실제 영상 재생·자막과 큰 글씨 화면에서의 조작은 확인하지 못했다.

## develop 통합 후 검증 범위 (2026-10-28)

홈 시작은 실제 `/start` 안내로 연결하고 가상 미리보기는 별도 링크로 진입한다. 브라우저 검사는 해당 경로로 갱신했다. 기본 실행은 동작·너비·접근성을 검사하며, 과거 스크린샷은 현재 화면의 승인 기준으로 사용하지 않는다. 시각 비교는 `VISUAL_REGRESSION=1` 환경변수를 명시한 경우에만 실행한다. 기존 기준 이미지는 이력이며 새 화면과 수동 비교·검토 후 갱신해야 한다. 이번 PR 통합 과정에서는 E2E와 시각 기준 갱신을 실행하지 않았다.
