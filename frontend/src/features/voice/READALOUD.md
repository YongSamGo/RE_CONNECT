# 공고 읽어주기 확대

PR #135 다음 단계다. 공개 공고에서 계약이 허용하는 제목·설명·일정·상세 장소·보수 상세·접수 안내 중 값이 있는 항목을 선택한다. 필수조건/서류는 `SpeechTargetOpportunity` 허용 필드가 아니므로 임의 텍스트로 우회하지 않는다. 원문이 잘린 경우 기존 상세 화면의 전체 원문 확인 안내를 유지한다.

- 버튼을 누른 뒤 `/me`의 서버 AI 처리 동의를 확인하고 `/speech`에 공고 ID·버전·필드·부분 번호만 보낸다. 미리보기 동의나 새로 지어낸 동의문을 사용하지 않는다.
- `X-Speech-Segment-Count`를 양의 안전한 정수로 검사한다. WAV·빈 응답 여부·현재 부분 범위·같은 참조의 전체 부분 수 일관성을 검사한다. 헤더가 없으면 전체 분량을 임의로 추정하지 않고 오류로 처리한다.
- 재생 종료가 다음 부분 요청을 자동 시작하지 않는다. 다음 버튼으로 요청하고 각 요청에 새 멱등 키를 쓴다. 버전 충돌은 최신 자료를 다시 불러오도록 안내한다.
- 하나의 재생기만 마운트한다. 항목 전환은 이전 요청을 중단하고 플레이어 pause/src 제거/load 및 object URL 해제를 수행한다. 중지·페이지 이탈·bfcache 복귀·언마운트도 기존 요청/메모리 수명 규칙을 따른다. 늦게 도착한 동의 응답이 음성 요청을 시작하지 않는지 시험한다.
- 실제 음성 서버/운영 동의문이 미확정이다. 정상 응답·플레이어는 테스트에서만 모형을 쓰며 앱에 주입하지 않는다. 실제 TTS 품질·모바일 재생 정책·녹음과 상호 중지는 후속 검증이다.
