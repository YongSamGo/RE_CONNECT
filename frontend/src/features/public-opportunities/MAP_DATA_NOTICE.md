# 행정구역 지도 데이터 출처

수도권 시·군·구 지도는 통계청 통계지리정보서비스(SGIS)가 제공하는 2026년 10월 1일 기준 행정동 경계 데이터에서 시·군·구 단위로 묶어 단순화했습니다.

> 본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: vuski/admdongkor, https://github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다.

자료: [vuski/admdongkor](https://github.com/vuski/admdongkor), 데이터 버전 `2026.10.17`, 지도 기준일 `2026-10-01`.

인천 지도 주변의 경기·서울 경계도 같은 자료의 행정동 경계를 단순화해 표시합니다. 주변 경계는 위치를 돕기 위한 참고용이며 선택 대상이 아닙니다.

전체 지역 지도는 같은 행정동 경계를 공통 좌표계로 변환하고 단순화해 표시합니다.

김포/인천 지도는 같은 자료의 행정동을 시·군·구 단위로 합치고 경계를 단순화했습니다. 작은 섬은 화면 가독성을 위해 일부 생략했습니다.

경기 남부 지도에서는 화성시 본토를 유지하고 작은 부속 섬의 표시를 생략합니다. 이는 지도 가독성을 위한 표시 단순화이며 검색 지역이나 행정구역 소속을 바꾸지 않습니다.
