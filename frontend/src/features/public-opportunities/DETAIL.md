## 사용과 상태

목록의 내부 상세 링크로 이동한 뒤 **공고 정보 불러오기**를 눌러 `GET /api/v1/opportunities/{opportunity_id}`만 호출한다. 자동 요청·재시도, 로그인·동의·프로필·자격·AI·신고·지원서 요청은 없다. UUID가 아닌 경로(기존 `/opportunities/preview` 포함)는 네트워크 요청 전에 주소 오류를 표시한다. 검색 복귀 시 이전 검색어를 주소나 저장소에서 복원하지 않는다.

- 로딩·취소·고정 오류·명시적 재조회·일일 한도를 구분한다. 404는 삭제/비공개 가능성을 안내하고 검색 복귀를 제공한다. 서버 오류 원문은 출력하지 않는다.
- 응답 ID와 요청 ID가 다르면 전체 응답을 거절한다. 최신 정보 재조회는 이전 내용을 제거하고 새 버전·모집 상태를 표시한다. 버전 번호만으로 현재 최신임을 보장하지 않는다.
- 공개 목록은 계속 마감 항목을 거절하지만, 상세는 마감 공고도 읽을 수 있다. 모집 마감·변경 확인 중·모집 상태 unknown에는 신청 안내 링크를 숨긴다. 실제 추천·지원서 차단은 서버가 별도로 보장해야 한다.
- 원문 일반 텍스트·원문 조건 근거·조건 해석 확인 필요·서류·일정·보수·장소·KST 마감/확인/검수 시각을 표시한다. 없는 정보를 생성하지 않는다. 날짜만 제공되면 시각을 붙이지 않는다. 설명이 잘렸으면 전체 원문 확인을 안내한다.
- 필수조건 빈 배열은 계약의 '명시된 필수조건 없음'으로 표시한다. 조건별 근거만 투영하며 연산·조건 그룹·역할 태그로 자격이나 적합도를 계산하지 않는다. 조건 조합은 공식 안내 확인 대상으로 명시한다. 서류 null과 빈 배열을 구분한다.
- 경로별 컴포넌트 수명과 기존 `useMemoryScope`를 사용한다. 취소·다른 공고 이동·언마운트·pagehide·bfcache 복귀 후 늦은 응답은 폐기한다. 메모리 상태를 영구 저장하거나 별도 로그에 남기지 않는다.

`parseDetail`은 unknown 응답에서 화면이 실제 사용하는 필드만 검사·투영한다. 요약 공통 검증에 더해 응답 ID, 설명/안내/서류/조건 문자열 길이, enum·null, 주당 시간 0~168, 확인/검수 timestamp를 확인한다. 표시하지 않는 조건 연산·태그 등 전체 스키마를 검증하는 도구가 아니며 서버 검수·JSON Schema 검증을 대체하지 않는다.

## 외부 링크 경계

`docs/data/sources.md`의 2026-10-14 확인 기록에 있는 다음 **두 상세 URL 형식만** 허용한다. 브라우저에서 외부 주소를 자동 조회하거나 이동하지 않는다.

- `https://www.work24.go.kr/wk/a/b/1500/empDetailAuthView.do`: `wantedAuthNo` 영문/숫자 1~100자, `infoTypeCd=VALIDATION`, `infoTypeGroup=tb_workinfoworknet`의 세 파라미터.
- `https://www.1365.go.kr/vols/P9210/partcptn/timeCptn.do`: `type=show`, `progrmRegistNo` 숫자 1~20자의 두 파라미터.

사용자정보·임의 포트·해시·공백/역슬래시·중복/추가 쿼리·다른 경로/호스트/프로토콜은 차단한다. 확인되지 않은 주소는 클릭 가능한 링크와 URL 원문을 표시하지 않고 확인 필요를 안내한다. 50플러스·워크넷 외 출처·변경된 공식 URL은 검증 후 허용 목록 갱신이 필요하다. 이 길이/패턴 제한과 신청 링크 보류 동작은 프로젝트 기술 판단이다.

허용 링크는 도메인·새 창을 명시하고 `noopener noreferrer` 및 `no-referrer`를 사용한다. 사용자 데이터나 검색어를 쿼리에 추가하지 않는다. 링크 열기는 신청 완료가 아니며 개인정보를 대신 제출하지 않는다. 외부 사이트 자체의 리다이렉트·접수·모집 상태는 이 브라우저 검사로 보증할 수 없다. **서버에서도 URL 허용 목록·출처/신청 URL과 해당 공고의 연결·검수 정책을 적용해야 한다.** 이 PR은 서버 보안 구현 완료 증거가 아니다.
