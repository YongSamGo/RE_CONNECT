# 확정 프로필 추천·자격 대조 (#85 후속)

`/journeys/:journeyId/recommendations`는 소유 프로필을 읽어 실제 확정 버전을 얻고 POST /recommendations를 호출한다. 미확정이면 추천 요청 없이 프로필 확인으로 안내한다. 수정 중인 초안의 experience ID로 이전 확정본의 근거를 대체하지 않는다. 현재 계약에 확정 경험 본문 조회가 없으므로 근거 경험 수·실제 연결 역량/표현·역할 수를 표시한다. 서버가 반환한 상위 5건과 순서를 사용하며 점수·성공 확률·임의의 역할 이름을 만들지 않는다.

추가 필터는 시·도 전체·활동 유형·보수로 확정 프로필 범위를 좁힌다. 미선택은 해당 키 생략이며 빈 배열/null을 보내지 않는다. 필터 변경 시 이전 추천과 자격 결과를 지운다. 결과가 없거나 실패해도 선택을 유지하고 자동 조건 완화/추가 추천 요청을 하지 않는다. 사용자가 필터나 프로필을 직접 바꾸거나 공개 검색으로 이동한다.

이전 확정본 기준 표시, 필수조건 없음, 확인 필요와 필요한 조건 수를 분리한다. 각 추천의 자세히 대조 버튼은 POST /opportunities/{id}/eligibility에 동일한 확정 참조와 화면 공고 버전을 보낸다. 개별 원문 조건·실제 비교 값·결과·확인 이유를 보여 주며 null(미확인)/[](없음 확인)을 구분한다. age의 비교 값은 출생 연도이므로 만 나이로 잘못 표시하지 않는다. 거주지와 희망 활동 지역을 바꾸지 않는다. AND/OR 묶음과 개별 조건 결과를 따로 표시해 OR의 일부 미충족을 종합 미충족으로 바꾸지 않는다. 현재 응답은 조건별 group_id를 포함하지 않으므로 프론트가 조건/묶음의 소속 관계를 추정하지 않는다.

런타임 파서는 소유 확정 참조·공고 버전·리비전 대신 사용하는 명시 버전·순위·중복 ID·텍스트/배열 한도·상태를 검사한다. 마감/변경 검토 중/미충족 추천이나 점수 필드를 가진 응답은 거절한다. 자격 재조회에서 변경/접근 상실을 감지하면 모든 개인 결과를 지우고 새 조회를 안내한다. 모든 결과·필터·오류는 화면 메모리에만 있으며 pagehide/언마운트/취소 후 늦은 결과는 적용하지 않는다. 공통 JourneyRoute의 reload/back_forward/BFCache 경계를 적용한다. 화면의 상세 링크는 최신 공개 상세·공식 원문·신고 화면으로 이동한다.

화면 대역 시험 12건은 실제 버전 요청/근거/이전 확정본, 미확정 차단, 필터/빈 결과 자동 완화 금지, 오류 선택 유지/포커스, unknown/미충족/OR 구분, 버전·세션 변경 시 삭제, 중복·취소·이탈, 파서와 axe 구조를 검사한다. 별도 계약 시험은 실제 ASGI 추천·자격 서비스+SQLite 공개본+메모리 체험 저장소의 HTTP 응답을 프론트 파서에 대조한다. 메모리 체험 대역을 Redis 통합이나 실제 운영 자료로 표시하지 않는다. 백엔드 Redis/PostgreSQL 경계 시험은 앞선 별도 기록을 따른다.

운영 정보 미정으로 #81 실제 동의/생성 진입점은 계속 비활성이다. 실제 공고×persona 평가 #65, 운영 HTTPS·대상 기기·스크린리더 및 전체 브라우저 여정은 미검증이다. #85 전체 통과/원격 이슈 완료로 기록하지 않는다. 상세 페이지 자체의 개인 자격 위젯은 체험 맥락 없이 임의 참조를 만들지 않으며 체험 추천 화면에서 대조한다.
