# 체험 프로필·역할 화면 (#84)

`/journeys/:journeyId/profile`는 서버 체험 ID를 받아 GET 프로필, 전체 초안 PATCH, 명시적 확정/재확정 POST와 역할 후보·제외/복원 API를 사용한다. 쿠키 세션과 소유권 검사는 서버에서 수행하며 URL의 ID를 권한으로 사용하지 않는다. 잘못된 ID는 요청 전에 거절한다. 기존 `/profile`의 가상 미리보기 확인을 서버 확정으로 바꾸지 않는다.

경험 내용·기간·역량, 전체 역량, 희망 지역·활동 유형·유급 선호·요일/시간, 이동 메모, 거주 지역·출생 연도·자격증·교육·활동 수행 조건을 직접 편집한다. 새 경험 ID는 null로 보내 서버가 부여한다. React의 임시 행 키는 서버 ID로 보내지 않는다. 희망 지역을 거주 지역으로 복사하지 않으며 거주 지역은 사용자가 직접 적용해야 입력된다. null(미확인)과 빈 목록(없음 확인)을 보존한다. 지역 목록은 공용 GET /regions를 사용한다.

초안 반영과 확정 버튼을 구분한다. 반영하지 않은 편집 중에는 확정/역할 변경을 막고, 확정 전 경험·희망 지역·활동 유형 누락은 요약에 포커스를 옮겨 안내한다. 확정본이 있을 때만 같은 화면에서 실제 경험 태그 근거와 역할 후보를 보여 준다. 수정 중에는 이전 확정본 기준임을 표시하고 재확정 후 이전 추천·자격의 재조회가 필요함을 안내한다. 회원 저장 성공이나 지원서 본문 자동 갱신으로 표현하지 않는다.

후보는 최대 20개이므로 후보의 체크박스만으로 전체 제외 목록을 재구성하지 않는다. 추가한 `GET /journeys/{id}/role-exclusions`에서 전체 목록과 리비전을 읽고, 보이지 않는 기존 제외 선택도 보존해 전체 교체 PUT을 보낸다. 전체 복원은 빈 목록을 전송한다. 후보/전체 제외/프로필 리비전이 다르면 역할 조작을 활성화하지 않는다. 확정 프로필·역할/제외 선택 조회가 순차인 만큼 동시 변경 시 안전하게 재조회해야 한다.

요청 중 중복 조작을 막고, 충돌/네트워크 오류에는 편집 내용을 유지한다. 최신 서버 내용 재조회는 로컬 편집을 교체한다고 안내한다. 만료·타인/없는 자원 응답은 본문을 지운다. pagehide·캐시 복원·언마운트 시 메모리와 진행 요청을 무효화하고 늦은 응답을 적용하지 않는다. 화면 입력 닫기는 화면 메모리만 지우며 서버 체험 삭제라고 표현하지 않는다.

가상 서버 응답을 쓴 화면 시험은 편집/확정 분리·null/빈 목록·최소 오류 포커스·화면 밖 제외 보존/전체 복원·충돌 입력 유지·중복 차단·늦은 응답 폐기·역할 근거 버전 검사와 axe 구조/레이블을 검증한다. 실제 ASGI HTTP 계약 시험은 SQLite/메모리 프로필의 GET 프로필/역할/전체 제외 응답을 프론트 파서에 통과시키며, 별도 백엔드 시험은 실제 Redis/PostgreSQL로 API 경계를 확인한다. 화면 시험 대역을 실제 서버 증거로 쓰지 않는다.

#43 후속: `종료하고 삭제`는 확인 후 실제 DELETE /journeys/{id}를 호출한다. 진행 요청을 무효화하고 204 뒤에만 메모리를 지워 시작으로 이동하며 서버 오류 시 입력을 보존한다. 단순한 `이 화면의 입력 닫기`는 서버 삭제가 아니다. 실제 서버의 소유권·멱등 삭제·늦은 완료 차단은 백엔드 시험으로 별도 검증했다.

이 체험 URL 자체를 새로고침/히스토리 재진입한 탐색 기록이 있으면 프로필 요청 전에 시작 화면으로 이동한다. 시작 화면을 새로고침한 뒤 SPA에서 새 체험으로 이동하는 경우는 막지 않는다. BFCache 복원도 시작으로 이동하고 삭제 확인 상태를 복원하지 않는다. 서버 수명/소유권을 대신하는 보안 경계는 아니며 실제 대상 브라우저의 탐색·캐시 동작은 기기 검증이 필요하다.

시작·동의·대화 화면은 아직 미리보기다. #81의 실제 처리 안내문 확정·동의·체험 생성 연결에서 이 URL로 이동해야 하며 현재 화면에 가짜 체험을 자동 생성하지 않는다. 실제 기관 공고·배포 HTTPS·모바일/스크린리더·화면 전체와 실제 Redis를 함께 묶는 브라우저 여정 검증은 남아 있다. 따라서 #84 전체를 통과로 기록하지 않는다.
