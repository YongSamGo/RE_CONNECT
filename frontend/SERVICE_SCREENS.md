# 서비스 화면 초안과 이동 경로

2026-10-28. 기존 홈·시작 안내·로그인 디자인을 기준으로 사용자 화면을 연결했다.
색상과 에스코어 드림 폰트, 흰 패널, 청색 주요 버튼, 본문 18px 이상과 큰 글씨 설정을 이어 쓴다.
홈과 시작 안내의 문구·항목 배치는 이번 작업에서 변경하지 않았다.

## 브라우저에서 확인하기

로컬 개발 서버의 `/guide`에서 사용자 과업별 진입점을 확인한다. 아래 표에는 호환 주소와 같은 화면 안의 패널도 포함하므로 행 수를 독립 화면 수로 세지 않는다.
이 목록은 화면에 임의의 회원·대화·공고·저장 결과를 주입하지 않는다.
선택한 체험이나 공고가 없는 주소는 해당 화면의 빈 상태와 시작 방법을 표시한다.
공통 화면 하단의 이용 안내 링크는 제공하지 않는다. 원래 디자인을 유지한 시작·로그인·공고 탐색 화면에서는 브라우저 뒤로가기를 사용한다.

| 화면 | 자료 선택 전 주소 | 실제 자료가 있는 경로·진입점 |
|---|---|---|
| 시작 전 안내 | `/start` | 기존 동의·체험 생성 API |
| AI와 경험 이야기 | `/conversation` | `/journeys/:journeyId/conversation` |
| 음성 입력 | `/voice` | 실제 대화 화면의 음성 입력 패널 |
| 내 경험 확인·수정·확정 | `/profile/review` (`/results`도 이곳으로 연결) | `/journeys/:journeyId/profile`, `/journeys/:journeyId/results` 모두 같은 과업 화면 |
| 추천 공고 | `/recommendations` | `/journeys/:journeyId/recommendations` |
| 공개 공고 탐색 | `/opportunities` | 공개 검색 API |
| 공고 상세 | `/opportunities/detail` | `/opportunities/:id` |
| 지원 조건 대조 | `/eligibility` | 실제 추천 공고의 필수조건 대조 패널 |
| 신청 준비 | `/preparation` | `/opportunities/:id/preparation` |
| 지원서 작성 | `/application` | `/journeys/:journeyId/opportunities/:opportunityId/preparation` |
| 저장할 자료 | `/save` | `/journeys/:journeyId/save`, `/journeys/:journeyId/drafts/:draftId/save` |
| 저장 동의·저장하기 | `/me/save` | 현재 회원에 연결된 저장 대기 또는 체험 저장 대상 |
| 저장 결과 | `/save/result` | 실제 저장 화면에서 프로필·지원서 API의 성공을 확인한 상태 |
| 로그인 | `/login` | 기존 카카오 로그인 안내·연결 |
| 내 정보·동의·계정 관리 | `/me` | 현재 회원 API |
| 내 프로필 | `/me/profile` | 현재 회원 저장 프로필 API |
| 저장 자료 목록·지원서 상세 | `/me/saved` | 현재 회원 자료 조회·편집·삭제 |

로그인 복귀 화면 `/auth/result`에도 동일한 패널 스타일을 적용했다.
로그인 결과나 저장 결과는 URL·화면 이동으로 성공 처리하지 않는다.
자료가 있어야 사용할 수 있는 작업은 자료 선택 전 비활성 또는 시작 경로로 표시한다.
저장 완료 UI는 실제 저장 요청이 성공하고 회원 상태를 다시 확인한 경우에만 표시한다.

## 연결한 이용 흐름

실제 대화 응답이 프로필 확인 단계로 전환되면 `정리한 경험 확인하기`로 내 경험 확인 화면에 이동한다.
초안 요약·수정·확정을 같은 화면에서 수행한 뒤 추천 공고 또는 회원 저장으로 이어진다. 결과 요약에서 편집 화면으로 다시 이동하던 단계를 없앴다.
프로필과 지원서는 저장 결과를 따로 표시해 일부만 저장된 상태와 전체 저장 완료를 구분한다.
공고의 신청 준비에서는 공식 서류 안내와 지원서 편집을 한 패널 안에 배치한다.
공식 신청처 이동은 실제 접수 완료로 처리하지 않는다.

## 초기 화면 연결 당시 검증 기록

아래는 전면 개편 전 기록이다. 현재 개편의 변경·확인 범위는 [개편 진행 기록](REDESIGN_PROGRESS.md)을 따른다. 개발 전용 `/dev/conversation`, `/dev/profile`은 예시 자료를 표시하며 실제 동의·확정·회원 저장 성공의 증거가 아니다.

- 관련 화면·실제 API 요청 경계 단위 테스트 13개 파일, 158개 테스트 확인. 저장 후 안내 문구 실패 1건을 수정하고 해당 테스트 5건 재확인.
- 타입 검사와 린트 통과.
- 브라우저에서 이용 안내, 결과, 추천, 지원서, 저장 선택 화면 배치를 확인.
- 실제 로그인 제공자·AI 모델·자료 저장의 전체 왕복, 실제 모바일 기기와 스크린리더는 이번 작업에서 검증하지 않았다.
- 전체 테스트와 E2E는 실행하지 않았다.
