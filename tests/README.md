# tests — 서비스를 넘나드는 시험

단위·통합 테스트는 각 프로젝트 안에 둔다 (`backend/tests/`, `frontend/` 안의 테스트). CI가 프로젝트 폴더에서 pytest·npm test를 실행하기 때문이다.

이 폴더에는 한 프로젝트 안에서 끝나지 않는 시험만 둔다.

| 폴더 (예정) | 내용 |
| --- | --- |
| `e2e/` | 브라우저에서 화면 → API → DB까지 이어지는 사용자 흐름 |
| `contract/` | API 계약 예제와 실제 응답 비교 (W01-02 계약 기준) |
| `security/` | 권한 우회·세션·삭제처럼 여러 서비스에 걸친 공격 시나리오 |

## 규칙

- 실제 개인정보를 쓰지 않는다. 가상 사용자·가상 공고만 쓴다.
- 모의 응답으로 통과한 시험과 실제 연동으로 통과한 시험을 구분해 기록한다.
