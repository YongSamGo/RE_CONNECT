# 로컬 한국어 읽어주기 로더 (#32 진행)

`app/tts.py`는 [고정 호환 코드](tts_compat/README.md)와 공식 모델의 해시를 오프라인 검증한 뒤 CPU에 적재한다. 요청 시 다운로드·외부 서비스 대체·사용자 화자/언어/지시 선택·참조 음성·화자 복제를 제공하지 않는다. 한국어와 Sohee를 고정한다. 기존에 다른 위치에서 import한 qwen 코드가 있으면 거절한다.

Python3.12 격리 환경에 기본 speech와 tts_compat의 런타임/개발 해시 잠금을 함께 설치하고, 모델과 호환 source를 먼저 준비해야 한다. [모델 준비](MODEL_PREPARATION.md)와 [코드 준비](tts_compat/README.md)의 명령을 따른다. 준비한 source와 모델은 서비스 실행 시 읽기 전용으로 배치해야 하며 bytecode를 생성하지 않는다. 이 문서의 CPU 시험은 운영 컨테이너 배치 증거가 아니다.

## 입력·출력과 정리

호출자는 백엔드에서 동의·소유권·표시 버전이 확인된 문장만 전달한다. 로더는1~2000자, 비어 있지 않은 문자열만 받으며 숨은 제어 문자와 모델 대화 토큰 경계를 거절한다. 문장을 자르거나 다른 문장으로 고쳐 읽지 않는다. 생성 코드가 codec 종료 토큰을 확인해야 WAV를 반환한다. 길이 한도에 닿은 부분 음성은 실패다.

출력은24kHz·mono·16bit PCM WAV이며16MiB 이하다. NaN·빈 파형·잘못된 rate/배열·디지털 무음·인코딩 실패를 거절한다. 반환형은 지울 수 있는 `bytearray`다. 로더가 가진 파형·PCM·인코더 버퍼는 성공/실패 뒤0으로 채운다. 반환 WAV는 호출자가 전달/재생 수명에 맞춰 비워야 한다. Python/네이티브 라이브러리의 모든 내부 임시 복사본을 완전 소거한다고 주장하지 않는다. 파일이나 영구 음성 캐시를 만들지 않는다.

현재 HTTP의 `/internal/speech`에는 연결하지 않았다. `/health/ready`도 계속503·tts:false다. 이 로더만으로 추론 시간 초과 시 native 연산 종료나 응답 버퍼 정리가 입증되지는 않는다. 후속 연결에서 공통 슬롯·55초 연산 제한·실제 연산 종료 확인·취소/실패 응답 정리를 함께 검증해야 한다.

## 실제 CPU 확인 (2026-10-18)

Ubuntu24.04/WSL·Python3.12.3에서 해시 잠금된 Torch2.14.1+cpu/Transformers5.19.0과 faster-whisper1.2.1/CTranslate2 4.8.2를 같은 프로세스에 적재했다. 두 로더의 합산 적재26.181초다. 공개 가상 문장만 사용했고 사용자 녹음은 사용하지 않았다. TTS의24kHz WAV를 평가용으로16kHz에 변환해 같은 프로세스의 Whisper에 전달했다. 생성 시간은 각각8.521/9.757/11.266초였으며 HTTP 왕복 시간은 아니다.

| 표시 문장 | 실제 재전사 | 음성 길이 | 판정 |
|---|---|---|---|
| 안녕하세요. | 안녕하세요 | 2.64초 | 마침표 제외 일치 |
| 공고 12번입니다. | 092번입니다. | 3.92초 | 내용 불일치, 청취 평가 필요 |
| 신청 마감은 10월 20일입니다. | 신청마감은 10월 20일입니다. | 4.64초 | 띄어쓰기 제외 일치 |

세 문장 모두 원문 문자열의 완전 일치는 실패했다. 두 문장만 문장부호·띄어쓰기 제외 비교가 일치했다. 숫자 문장의 오류 원인이 TTS인지 STT인지는 이 자동 시험만으로 구분할 수 없다. 읽어주기 품질 통과로 처리하지 않으며 숫자/금액/날짜/공고 문장의 사람 청취 평가를 계속해야 한다. 한 랩탑의3개 표본으로 성능·품질 기준을 보장하지 않는다.

호환 회귀13개와 로더 입력/출력·실패 시 버퍼·오염된 패키지/가중치 거절22개, 합계35개 시험이 통과했다. 같은 설치 환경에서 기본 STT27개도 통과했다. 자체 코드 Bandit 지적0이다. 실제 HTTP·프로세스 중단/배출·컨테이너 자원 제한·EC2/GPU·대상 기기/브라우저 재생은 남아 있다. 운영 동의 정보 미정에 따른 실제 시작 비활성도 유지한다.
