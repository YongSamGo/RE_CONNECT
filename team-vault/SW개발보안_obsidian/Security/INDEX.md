# 공식 개발보안 지식 베이스

두 공식 PDF의 원문을 장·절과 보안약점 단위로 탐색합니다. 이 인덱스의 키워드·대응표·프로젝트 연결은 탐색용 메타데이터이며 공식 원문이 아닙니다.

진입 순서: 통합 인덱스 → 2023 Python 가이드 또는 2021 진단가이드 → 장·절·개별 원문. 아래 목차에서 원문으로 바로 이동할 수 있습니다.

- [소프트웨어 보안약점 진단가이드 (2021)](#sw-diagnosis-2021)

LLM 프롬프트 인젝션·호출 비용 상한, 사용자 동의·보관기간·삭제 정책의 구체적 기준은 두 가이드의 독립 항목에서 직접 다루지 않습니다. 위 연결은 관련 원칙을 찾기 위한 탐색 보조이며 현대 기술의 검증이나 법률·제품 정책 판단을 대신하지 않습니다.

LLM 관련 위험은 KISA 원문 대신 [LLM·AI 도구 점검 기준](../../../.claude/skills/kisa-secure-coding-python/references/llm-security.md)에 OWASP 「Top 10 for LLM Applications」(2025) 번호로 정리했습니다. 프롬프트 인젝션은 `LLM-01`, 호출 비용 상한은 `LLM-10`, 저장소 숨은 문자·에이전트 지시 파일 경로는 `AGT-01~04`입니다. 볼트 밖 저장소 파일이라 Obsidian에서는 열리지 않고 GitHub나 편집기에서 엽니다. 동의·보관기간·삭제 정책은 아직 별도 기준이 없습니다.
