| 1 | SQL 삽입 | SQL 질의문을 생성할 때 검증되지 않은 외부 입력 값을 허용하여 악의적인<br>질의문이 실행가능한 보안약점 |

| 6 | 위험한 형식 파일 업로드 | 파일의 확장자 등 파일형식에 대한 검증없이 파일 업로드를 허용하여 공격이<br>가능한 보안약점 |
| 7 | 신뢰되지 않는 URL<br>주소로 자동접속 연결 | URL 링크 생성에 검증되지 않은 외부 입력값을 허용하여 악의적인 사이트로<br>자동 접속 가능한 보안약점 |

| 12 | 서버사이드 요청 위조 | 서버 간 처리되는 요청에 검증되지 않은 외부 입력값을 허용하여 공격자가<br>의도 한 서버로 전송하거나 변조하는 보안약점 |
| 13 | HTTP 응답분할 | HTTP 응답헤더에 개행문자(CR이나 LF)가 포함된 검증되지 않은 외부<br>입력값을 허용하여 악의적인 코드가 실행 가능한 보안약점 |
| 14 | 정수형 오버플로우 | 정수형 변수에 저장된 값이 허용된 정수 값 범위를 벗어나 프로그램이<br>예기치 않게 동작 가능한 보안약점 |
| 15 | 보안기능 결정에 사용되는<br>부적절한 입력값 | 보안기능(인증, 권한부여 등) 결정에 검증되지 않은 외부 입력값을 허용하여<br>보안기능을 우회하는 보안약점 |
| 16 | 메모리 버퍼 오버플로우 | 메모리 버퍼의 경계값을 넘어서 메모리값을 읽거나 저장하여 예기치 않은<br>결과 가 발생하는 보안약점 |

#### 2. 보안기능

| 번호 | 보안약점 | 설명 |
| --- | --- | --- |
| 1 | 적절한 인증 없는 중요<br>기능 허용 | 중요정보(금융정보, 개인정보, 인증정보 등)를 적절한 인증없이 열람<br>(또는 변경) 가능한 보안약점 |
| 2 | 부적절한 인가 | 중요자원에 접근할 때 적절한 제어가 없어 비인가자의 접근이 가능한<br>보안약점 |
| 3 | 중요한 자원에 대한<br>잘못된 권한 설정 | 중요자원에 적절한 접근 권한을 부여하지 않아 중요정보가 노출·수정<br>가능한 보안약점 |
| 4 | 취약한 암호화 알고리즘 사용 | 중요정보(금융정보, 개인정보, 인증정보 등)의 기밀성을 보장할 수 없는<br>취약한 암호화 알고리즘을 사용하여 정보가 노출 가능한 보안약점 |
| 5 | 암호화되지 않은 중요정보 | 중요정보(비밀번호, 개인정보 등) 전송 시 암호화 또는 안전한 통신채널을<br>이용하지 않거나, 저장 시 암호화하지 않아 정보가 노출 가능한 보안약점 |
| 6 | 하드코드된 중요정보 | 소스코드에 중요정보(비밀번호, 암호화키 등)를 직접 코딩하여 소스코드<br>유출 시 중요정보가 노출되고 주기적 변경이 어려운 보안약점 |
| 7 | 충분하지 않은 키 길이<br>사용 | 암호화 등에 사용되는 키의 길이가 충분하지 않아 데이터의 기밀성·<br>무결성을 보장할 수 없는 보안약점 |
| 8 | 적절하지 않은 난수 값<br>사용 | 사용한 난수가 예측 가능하여, 공격자가 다음 난수를 예상해서 시스템을<br>공격 가능한 보안약점 |
| 9 | 취약한 비밀번호 허용 | 비밀번호 조합규칙(영문, 숫자, 특수문자 등) 미흡 및 길이가 충분하지<br>않아 비밀번호가 노출 가능한 보안약점 |
| 10 | 부적절한 전자서명 확인 | 프로그램, 라이브러리, 코드의 전자서명에 대한 유효성 검증이 적절하지<br>않아 공격자의 악의적인 코드가 실행 가능한 보안약점 |
| 11 | 부적절한 인증서 유효성 검증 | 인증서에 대한 유효성 검증이 적절하지 않아 발생하는 보안약점 |
| 12 | 사용자 하드디스크에 저장<br>되는 쿠키를 통한 정보노출 | 쿠키(세션 ID, 사용자 권한정보 등 중요정보)를 사용자 하드디스크에<br>저장되어 중요정보가 노출 가능한 보안약점 |
| 13 | 주석문 안에 포함된 시스템<br>주요정보 | 소스코드 주석문에 인증정보 등 시스템 주요정보가 포함되어 소스코드<br>노출 시 주요정보도 노출 가능한 보안약점 |
| 14 | 솔트 없이 일방향 해쉬<br>함수 사용 | 솔트를 사용하지 않고 생성된 해쉬 값으로부터 공격자가 미리 계산된 레인<br>보우 테이블을 이용하여 해쉬 적용 이전 원본 정보를 복원가능한 보안약점<br>*솔트 : 해쉬 적용하기 전 평문인 전송정보에 덧붙인 무의미한 데이터 |
| 15 | 무결성 검사 없는 코드<br>다운로드 | 소스코드 또는 실행파일을 무결성 검사 없이 다운로드 받아 실행하는<br>경우, 공격자의 악의적인 코드가 실행 가능한 보안약점 |
| 16 | 반복된 인증시도 제한 기능<br>부재 | 인증 시도 수를 제한하지 않아 공격자가 반복적으로 임의 값을 입력하여<br>계정 권한을 획득 가능한 보안약점 |

#### 3. 시간 및 상태

| 번호 | 보안약점 | 설명 |

| 번호 | 보안약점 | 설명 |
| --- | --- | --- |
| 1 | 오류 메시지 정보노출 | 오류메시지나 스택정보에 시스템 내부구조가 포함되어 민감한 정보,<br>디버깅 정보가 노출 가능한 보안약점 |

| --- | --- | --- |

| 2 | 제거되지 않고 남은<br>디버그 코드 | 디버깅을 위한 코드를 제거하지 않아 인가되지 않은<br>사용자에게 중 요정보가 노출 가능한 보안약점 |  |
| 3 | Public 메서드부터 반환된<br>Private 배열 | Public으로 선언된 메소드에서 Private로 선언된 배열을<br>반환(return)하면 Private 배열의 주소 값이 외부에<br>노출되어 해당 Private 배열값을 외부에서 수정 가능한<br>보안약점 |  |
| 4 | Private 배열에<br>Public 데이터 할당 | Public으로 선언된 데이터 또는 메소드의 인자가<br>Private으로 선언된 배열에 저장되면 이 Private 배열을<br>외부에서 접근하여 수정 가능한 보안약점 |  |
