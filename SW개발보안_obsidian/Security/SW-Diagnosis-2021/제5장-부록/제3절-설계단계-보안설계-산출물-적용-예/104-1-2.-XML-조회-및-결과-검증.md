구현방안

XML 문서에 대한 조회 기능은 XQuery 표현식을 이용하여 파라미터화된 쿼리를 만들고, 바인딩 함수를 
이용하여 입력 값을 안전한 문자열로 필터링하여 적용, 실행될 수 있도록 한다.

개발가이드에는 안전한 XML 조회 및 결과 검증에 필요한 XQuery 표현식의 사용 방법과 필터링 
방법 등을 제시하고 있다.
