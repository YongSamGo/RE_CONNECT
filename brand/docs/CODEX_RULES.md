# Codex 브랜드 작업 규칙

- 마스터는 `brand/source/original-reference.png`이며 덮어쓰지 않습니다.
- 로고 실루엣·곡률·색감·입체 음영·워드마크를 새로 그리거나 바꾸지 않습니다.
- 투명화가 가장자리나 반투명 표현을 손상하면 투명 자산을 만들지 않습니다.
- PNG를 실제 벡터인 것처럼 표기하지 않습니다.
- 브랜드 팔레트는 `brand/tokens/colors.json`과 `frontend/src/index.css`에서 동기화합니다.
- 웹사이트 변경은 사용자가 요청한 범위에 한정하고 기존 화면 레이아웃과 기능을 보존합니다.
- 디자인 자료에 없는 폰트를 임의로 적용하지 않습니다.
