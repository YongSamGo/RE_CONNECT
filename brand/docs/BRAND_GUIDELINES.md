# 브랜드 가이드

## 서비스와 표현

다시잇다는 시니어의 경험과 역량을 새로운 사회적 기회에 연결하는 서비스입니다. 로고 심볼은 맞물린 두 C자형 구조와 입체적인 블루 곡면입니다. 웹 상단은 바탕화면 원본 심볼 PNG와 에스코어 드림 한글 `다시잇다`를 조합합니다. 헤더에는 슬로건을 표시하지 않습니다.

## 컬러

웹 UI는 흰색과 연한 블루를 바탕으로 사용하고 Primary Blue를 주요 행동에 사용합니다. 본문은 높은 대비의 어두운 블루로 유지합니다. 원본 로고의 그라데이션은 로고 안에서만 사용하며 카드·버튼 등에 복제하지 않습니다. 구체적 값은 `tokens/colors.json`을 참고합니다.

## 인터페이스

현재 프로젝트의 글꼴, 여백, 컴포넌트, 화면 구조를 유지합니다. 이 작업은 공통 색상 토큰과 상단 로고·파비콘에 한정했습니다. 새 장식, 과한 그라데이션, 레이아웃 재설계는 포함하지 않습니다. 오류와 성공 상태는 색 외에도 문구·형태로 구분합니다.

## 자산 상태

상단 심볼 원본은 `source/logo-symbol-original.png`입니다. 이 PNG는 투명 배경이나 실제 벡터가 아니며 옅은 배경을 포함합니다. 자동 배경 제거는 심볼 가장자리와 밝은 블루 음영을 손상할 수 있어 적용하지 않았습니다. 이전 락업과 대화 첨부 이미지는 참고용으로 보존합니다.
