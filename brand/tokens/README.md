# 브랜드 컬러 토큰

브랜드 시안의 초기 HEX 값입니다. 로고의 입체 그라데이션을 UI 컨트롤에 복제하지 않고 단색 토큰으로 사용합니다.

| 토큰 | HEX | 역할 |
|---|---|---|
| Deep Blue | `#135BBA` | 진한 강조, 활성 요소 |
| Primary Blue | `#2172D1` | 주요 버튼과 링크 |
| Bright Blue | `#358EE5` | 활성·강조 상태 |
| Sky Blue | `#53ADF6` | 밝은 포인트 |
| Light Blue | `#79BAF1` | 보조 색상 |
| Soft Blue | `#B1D8FA` | 부드러운 보조 영역 |
| Pale Blue | `#CCE5FC` | 선택 영역과 약한 경계 |

`frontend/src/index.css`의 앱 런타임 토큰도 같은 팔레트 변수를 사용합니다. 본문 텍스트는 어두운 블루, 바탕은 흰색에 가까운 블루, 주요 버튼은 Primary Blue입니다. 오류 색상은 브랜드 색과 구분된 의미 색상으로 유지합니다.
