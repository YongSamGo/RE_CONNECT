# 다시잇다 개발 전체 지도

`development-map.html`을 브라우저에서 열면 됩니다. 인터넷 연결과 서버가 필요 없는 단일 파일입니다.

- 휠 또는 ＋/−: 확대·축소. 드래그: 이동.
- 전체 흐름 / 지도 전체 / 실행 작업 / 설계 명세: 영역 이동.
- 영역 선택: W01~W14 묶음 이동.
- 검색: 작업 ID·기능·API·문장 검색. Enter: 검색 결과 순회.
- 항목 클릭: 출처·행 번호·절별 원문 확인. 선행·후속 작업 버튼: 해당 작업 이동.
- 미니맵 클릭: 지도 위치 이동. 방향키: 이동, Home: 전체 흐름, Esc: 선택 해제.

`development-map.svg`는 8,400 × 20,812 좌표의 한 장짜리 벡터 지도입니다. 확대해도 글자와 도형이 선명합니다. `development-map-preview.png`는 전체 배치를 보는 축소 이미지이며 상세 열람에는 HTML 또는 SVG를 사용합니다.

## 포함 범위와 출처

Plan/Implementation_Plan.md 및 Plan/01~05 설계 명세를 기준으로 14개 영역, 106개 작업, 232개 절별 항목을 포함합니다. 245개 선행 관계는 각 작업 카드의 **먼저 완료** 필드에서 추출했습니다. 선택한 작업에 관련된 관계만 표시하며 카드 위의 글자를 가리지 않도록 연결선을 뒤에 배치했습니다.

작업 카드에는 담당·협력·우선순위·선행 조건·진행 단계·완료 조건이 있습니다. 설계 영역에는 UX, 데이터 필드·상태·보관, 아키텍처·API, 기능 F01~F11, 위협·운영 한도·모델 후보·검증·일정·제출·보안 근거를 담았습니다. 실행 계획의 목표 게이트·시간 배분·계약 보완·API/데이터 추적표·인계 양식도 포함합니다.

개요 도식은 탐색용 재배치입니다. 지도 본문은 Markdown의 제목·강조·링크 표시를 읽기 위한 텍스트로 변환합니다. Mermaid 도식은 본문에서 안내 문구로 대체하고 절별 원문을 상세 패널에 그대로 보존합니다. 표는 행별 텍스트로 표시합니다. 원문 내용·Markdown·Mermaid는 상세 패널과 map-data.json에 보존합니다. 원본 계획 문서는 변경하지 않았습니다. manifest.json에 원본 파일의 SHA-256을 기록했습니다.

문서 기준일은 2026-10-13입니다. 모든 개발 작업은 문서의 미착수 상태로 표시했습니다. 날짜는 목표이며 실제 착수·연동·배포·검증 통과를 확인한 결과가 아닙니다. 후보 모델, 구체적 TTL·한도·추천 점수·정책은 프로젝트 판단입니다. 계획에 인용된 공식 기술 문서를 새로 검증한 결과로 해석하지 않습니다. 계약 보완 제안은 확정된 기존 API와 구분된 원문에 따라 표시합니다.

## 지도 생성 시 적용한 출력 보호

AGENTS.md → SW개발보안_obsidian/Security/INDEX.md → 아래 원문을 참조했습니다.

- 프로젝트 상대경로: `SW개발보안_obsidian/Security/Python-2023/제2장-시큐어코딩-가이드/제1절-입력데이터-검증-및-표현/009-4.-크로스사이트-스크립트(XSS).md`
- 장·절: 제2장 제1절 4항, 「나. 안전한 코딩기법」.
- PDF: 28~34쪽, 안전한 코딩기법 30쪽. 인쇄 페이지와 구분합니다.
- 적용: SVG 텍스트를 html.escape로 이스케이프하고 상세·검색 결과를 textContent로 표시합니다. 데이터 JSON의 `<`, `>`, `&`를 유니코드 이스케이프로 저장해 스크립트 경계에 삽입되는 것을 방지합니다. 문서의 링크·예제·HTML을 실행하지 않습니다.

프로젝트 기능의 보안 근거는 계획에 수록된 경로·장절·PDF 페이지를 지도와 상세 원문에 유지했습니다. 이번 작업은 서비스 구현의 보안 검증이 아닙니다.

## 검증과 갱신

build_map.py를 실행해 같은 원본에서 HTML·SVG·데이터·manifest를 갱신할 수 있습니다. Windows의 맑은 고딕과 Pillow를 사용합니다. verify_map.cjs는 설치된 Edge와 Playwright를 사용해 검색·이동·확대·관계 표시·텍스트 경계·모바일 가로 넘침·원문 절별 대응을 검사하며 verification.json에 결과를 기록합니다. 실행 환경 경로는 스크립트 상단에 있습니다.
