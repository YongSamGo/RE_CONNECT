# 공공 API 수집 경계

`fetch.py`는 확인된 공공 API의 고정 오퍼레이션만 HTTPS로 호출하고, 제한된 XML을 메모리에서 파싱한다. `FetchRequest`에 URL·헤더·임의 query를 받을 필드는 없다. 운영자/스케줄러가 인증키를 `SecretStr`로 제공한다.

외부 본문은 `UntrustedDocument`다. 파싱 성공이 사실 확인·공개 승인·정규화 성공을 뜻하지 않는다. #46에서 계약에 맞게 최소 필드를 정규화하고 #47에서 버전 저장을 연결한다. 이 모듈은 DB·파일·브라우저·LLM에 원문을 전달하지 않으며 HTTP 라우트도 만들지 않는다.

오류는 `FetchStatus`만 반환한다. 수집 실패를 공고 0건으로 해석하거나 마지막 성공 시각을 갱신하면 안 된다. 실행 상태·중복 실행 제어·스케줄러는 #49에서 연결한다. 세부 제한과 검증 범위는 [안내](../../../../docs/data/safe-fetch.md)를 따른다.
