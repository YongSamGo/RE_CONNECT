# 공고 원문 정규화

`normalize.py`는 확인된 원문 필드로 `OpportunityContent` 검수 대기 후보를 만드는 순수 함수다. 수집·DB 저장·LLM·공개 승인을 수행하지 않는다. [입력/출력·미확인 매핑·설명 저장 계약](../../../../docs/data/normalization.md)을 따른다.

#45의 안전 파서가 만든 목록/상세 `item`은 `normalize_items`로 전달한다. 중복·중첩 필드를 사전으로 덮어쓰지 않는다. 필수조건의 미해석 상태와 미확인 코드는 검수 전까지 보존한다. 원문이나 후보를 로그에 넣지 않는다.

공개 승인·정규화 완료와 후보 생성을 구분한다. #47 저장 연결에서 내용/설명 절단 표시를 함께 넘기고, 검수 사유·미확인 값의 보관과 조건 해소를 연결해야 한다.
