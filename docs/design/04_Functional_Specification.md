기준일: 2026-10-13 · 버전: v1.1 · 상태: 사용자 승인 설계 명세(EC2 로컬 추론 반영)

## F01. 진입·동의·체험 생성

- **UX:** UX01~02.
- **사전조건:** AI 처리 안내문이 EC2 자체 추론·AWS 호스팅/RDS 저장·리전·보관 정책과 일치한다.
- **입출력:** 동의 버전 → 체험 ID·만료·초기 질문.
- **처리:** 안내 → 동의 확인 → 서버 체험 생성 → 첫 질문.
- **규칙:** 로그인 없이 시작한다. AI 동의와 영구 저장 동의를 구분한다.
- **실패:** 동의가 없으면 AI 처리를 시작하지 않고 공개 공고 탐색을 제공한다.
- **보안:** 체험 소유권·생성 제한·안전한 세션.
- **완료 기준:** 미동의 요청에서 AI 호출이 발생하지 않는다.
- **담당·우선순위:** 프론트엔드/백엔드, P0.
- **시험:** 미동의·잘못된 동의 버전·비회원 정상 시작·회원 저장 프로필 가져오기·세션 만료 후 시작.

## F02. 음성·텍스트 대화

- **UX:** UX03~04.
- **선행:** F01.
- **입출력:** 텍스트 또는 음성 → 확인한 텍스트·다음 질문·초안.
- **처리:** 녹음 종료 → EC2 로컬 faster-whisper STT → 사용자 수정·보내기 → Ollama + Qwen3 구조화 추출 → 응답 검증 → 초안 반영.
- **규칙:** 한 번에 질문 하나. 음성과 텍스트를 전환할 수 있다. 전사 확인은 프로필 확정을 대신하지 않는다.
- **실패:** 전사 실패는 재녹음·직접 입력, 추출 실패는 입력 유지·재시도·수동 수정.
- **보안:** 음성 크기·형식 제한, 호출 제한, 원본 음성 정리, 최소 정보 전송.
- **완료 기준:** 수정한 전사만 추출에 사용하며 성공·실패·취소 경로에서 음성이 영구 저장되지 않는다.
- **담당·우선순위:** 프론트엔드/AI·데이터/백엔드, P0.
- **시험:** 권한 거부·무음·미지원 형식·90초/6MiB 경계·전사 수정·취소·추출 형식 오류·연결 중단·로그/임시 파일 내 음성 잔여 확인·로컬 모델 준비 실패·외부 AI 추론 통신 없음.

## F03. 프로필 수정·확정·재확정

- **UX:** UX05·UX09.
- **선행:** F02 또는 회원 저장 프로필.
- **입출력:** 초안 수정·확정 요청 → ConfirmedProfile.
- **처리:** 초안 조회 → 수정·삭제 → 최소 항목 검사 → 명시적 확정 → 새 버전.
- **규칙:** 경험·지역·활동 유형이 최소 요건이다. 미확인 조건은 유지한다. 승인 전 정보로 후속 판단하지 않는다.
- **실패:** 최소 항목 누락은 해당 항목 안내, 버전 충돌은 최신 내용 재조회.
- **보안:** 자기 자료만 변경, 클라이언트의 확정·소유권 값 신뢰 금지.
- **완료 기준:** 미확정 초안 참조의 추천 요청이 거절되고 재확정 시 이전 결과가 구분된다.
- **담당·우선순위:** 백엔드/프론트엔드, P0.
- **시험:** 최소 항목별 누락·초안 직접 수정·확정 전 추천 차단·기준 리비전 충돌·재확정 후 추천 갱신·지원서 재검토 표시.

## F04. 경험 기반 역할 발견

- **UX:** UX05의 확정 후 영역.
- **선행:** F03.
- **입출력:** 확정 경험·역량 → 역할 후보·근거 경험 ID.
- **처리:** 역할 사전 대조 → 근거 있는 후보 구성 → 제외·복원 선택.
- **규칙:** 직업명과 사회참여 역할을 구분한다. 역할 제안을 자격 보유·채용 가능의 보장으로 표현하지 않는다.
- **실패:** 연결 근거가 없으면 임의 후보 대신 공고 탐색 경로를 제공한다.
- **보안:** 존재하는 역할·경험 ID만 사용한다.
- **완료 기준:** 모든 후보에 확정 경험 근거가 있고 제외 선택이 추천에 반영된다.
- **담당·우선순위:** AI·데이터/프론트엔드, P1.
- **시험:** 초안 차단·존재하지 않는 경험/역할 ID·근거 없음·제외/복원·타 체험 제외 목록 접근.

## F05. 공고 수집·정규화·검수

- **UX:** UX10.
- **사전조건:** 출처별 접근·이용 조건·실제 필드를 확인한다.
- **입출력:** 승인된 API·공식 자료·수동 입력 → OpportunityVersion.
- **처리:** 출처 확인 → 수집 → 안전한 파싱 → 정규화 → 중복·변경 판별 → 검수 → 공개.
- **규칙:** 제목·기관·지역/원격·모집 상태·공식 접수 경로를 확인한다. 중요한 조건 변경은 재검수한다.
- **실패:** 실패 이력을 기록하고 마지막 성공 시각을 유지한다. 실패를 종료·삭제로 해석하지 않는다.
- **보안:** 고정 통신 대상, SSRF·XXE·과대 응답 방어, 운영자 권한.
- **완료 기준:** 같은 외부 ID 재수집 시 중복이 없고 미검수·종료 공고가 추천되지 않는다.
- **담당·우선순위:** AI·데이터/백엔드, P0.
- **시험:** 같은 ID 반복·중요 변경·필수 필드 누락·미확인 지역·모집 종료·일시 누락·타임아웃·악성 XML·과대 응답·48시간 확인 지연.

## F06. 검색·추천·근거 표시

- **UX:** UX06~07.
- **선행:** F03·F05·F07.
- **입출력:** 확정 프로필·선택 필터 → Recommendation[].
- **처리:** 공개·모집 중 후보 → 지역·유형·명백한 미충족 필터 → 역량·키워드 매칭 → 정렬 → 근거·확인사항 표시.
- **규칙:** 초기 점수는 역량 태그 일치 0.7, 키워드 일치 0.3으로 정규화한다. 동점은 마감이 가까운 공고, 공고 ID 순서로 정렬한다. 상위 5건을 우선 제시한다.
- **실패:** 결과가 적으면 그대로 표시한다. 필수조건을 몰래 완화하지 않는다.
- **보안:** 확정 프로필 소유권·공개본 검사, 입력 바인딩, 일반 텍스트 출력.
- **완료 기준:** 추천 근거가 확정 경험과 공개 공고에 연결되고 전체 자격 판정에서 미충족인 필수조건이 추천에 포함되지 않는다.
- **담당·우선순위:** AI·데이터/백엔드/프론트엔드, P0.
- **시험:** 미확정 입력·마감/미검수/보류 제외·OR 그룹 충족 후보 유지·확인 필요 표시·0~5건 결과·역할 제외·동점 정렬·무근거 추천 차단.

### 정렬 계산의 구현 기준

1. 정규화한 역량 태그 집합은 공백·중복을 제거하고 영문 대소문자를 통일한다. 역할 사전의 확인된 별칭만 같은 태그로 처리한다.
2. 역량 점수는 프로필과 공고 태그의 Jaccard 유사도(`교집합 수 / 합집합 수`)다. 합집합이 비면 0이다.
3. 키워드는 확정 경험·역량의 공백 단위 토큰 중 2자 이상을 중복 제거한 집합이다. 공고 제목·역할·역량·설명에서 일치하는 토큰 수를 전체 프로필 토큰 수로 나눈다. 토큰이 비면 0이다.
4. `score = 0.7 × skill_score + 0.3 × keyword_score`. 점수가 0이거나 연결 경험 근거를 만들 수 없으면 맞춤 추천에서 제외하고 일반 공고 탐색 경로를 제공한다.
5. 날짜만 있는 마감은 날짜 단위로 비교한다. 알려진 마감이 없는 후보는 동점에서 뒤에 둔다. 근거 없는 정확한 마감 시각을 만들지 않는다.

검색·점수 계산은 자격 판정과 별개다. OR 그룹의 단일 조건 미충족만으로 전체 충족 후보를 제거하지 않는다. 이 점수는 프로젝트 기본값이며 공식 보안 가이드 기준이 아니다.

## F07. 자격조건 대조

- **UX:** UX07.
- **선행:** F03·F05.
- **입출력:** 확정본·공고 조건 → EligibilityResult.
- **처리:** 지원 연산 검증 → 기준일·원문 확인 → 조건별 비교 → AND/OR 그룹 평가 → 전체 판정.
- **규칙:** 논리 그룹 평가 후 독립 필수조건 또는 필수 그룹이 미충족이면 전체 미충족. 미충족은 없지만 불명확하면 확인 필요. 확인한 필수조건이 모두 충족하면 조건 충족.
- **경계:** 출생연도만으로 만 나이가 경계에 걸리면 확인 필요. 거주지역과 활동 희망지역을 혼동하지 않는다. 미해석 조건은 통과로 처리하지 않는다.
- **실패:** 입력 형식 오류는 422, 기준 버전 충돌은 409로 반환한다. 조건·연산·기준일을 해석할 수 없으면 해당 판정을 확인 필요로 보존하고 임의 추정하지 않는다.
- **보안:** LLM이 판정을 결정하거나 변경하지 않는다.
- **완료 기준:** 누락·경계·AND/OR·기준일 변경 테스트를 통과한다.
- **담당·우선순위:** 백엔드/AI·데이터, P0.
- **시험:** 누락 자격·출생연도 연령 범위·거주/활동 지역 혼동·AND 및 OR 3상태 조합·기준일 없음·미해석 조건·버전 변경 후 재평가.

### 3상태 논리 기준

| 논리 | 결과 |
|---|---|
| AND | 하나라도 미충족이면 미충족. 전부 충족이면 충족. 나머지는 확인 필요 |
| OR | 하나라도 충족이면 충족. 전부 미충족이면 미충족. 나머지는 확인 필요 |

원문에 필수조건이 없다고 검수한 공고는 `명시된 필수조건 없음`으로 설명하고, 사용자에게 선발·신청 성공을 보장하지 않는다. 조건이 있는데 해석하지 못한 공고는 확인 필요다.

## F08. 신청 준비·지원서 작성

- **UX:** UX08.
- **선행:** F03·F05·F07.
- **입출력:** 확정 프로필·공고 → 서류 안내·자기소개·지원동기 초안.
- **처리:** 공식 절차 표시 → EC2의 Ollama + Qwen3 초안 생성 또는 직접 작성 → 사용자 수정·승인 → 복사·공식 안내 이동.
- **규칙:** 확정 사실만 사용한다. 공고에 없는 서류를 필수로 추가하지 않는다. 자동 제출·발송은 없다.
- **실패:** AI 장애 시 직접 작성한다. 공고 종료·중요 변경 시 갱신 확인을 요구한다.
- **보안:** 초안은 임시 보관, 사용자 승인 전 영구 저장 금지.
- **완료 기준:** 허위 경력·자격을 생성하지 않고 복사한 문장이 편집 내용과 일치한다.
- **담당·우선순위:** AI·데이터/프론트엔드/백엔드, P0.
- **시험:** AI 실패 후 직접 작성·미승인 저장 차단·없는 서류/자격 생성·근거 변경·복사 실패 안내·온라인/전화/방문/이메일 경로·외부 이동이 신청 완료로 기록되지 않음.

## F09. 회원 인증·저장·삭제

- **UX:** UX01·UX05·UX08·UX09.
- **입출력:** 카카오 인증·저장 동의·승인 자료 → 저장 버전·삭제 상태.
- **처리:** 인증 검증 → 내부 세션 → 동의 → 자료 소유권·승인 상태 확인 → 암호화 저장.
- **규칙:** 프로필·지원서만 저장한다. 철회·프로필 삭제·탈퇴 시 관련 전 버전과 파생 자료도 삭제한다.
- **실패:** 로그인 취소·동의 누락·저장 실패에서 저장 완료로 표시하지 않는다.
- **보안:** state·세션 교체·CSRF·소유권·재인증·암호화.
- **완료 기준:** 다른 사용자의 자료 접근이 차단되고 삭제 후 조회·늦은 응답·복구로 자료가 되살아나지 않는다.
- **담당·우선순위:** 백엔드/프론트엔드, P0.
- **시험:** 콜백 위조/재사용·로그인 취소·일회성 저장 대기 만료·같은 저장 요청 재전송·타 사용자 자료·기존 버전 충돌·개별 삭제·철회·탈퇴·암호문 변조·삭제와 AI 완료 경합·백업 복구.

## F10. 운영자 관리·오류 신고

- **UX:** UX07·UX10.
- **입출력:** 공고 변경·검수·신고 → 공개 상태·처리 결과·감사 기록.
- **처리:** 운영자 인증·MFA → 권한 확인 → 변경·검수 → 상태 반영 → 감사 기록.
- **규칙:** 운영자는 개인 프로필·지원서를 열람하지 않는다. 신고는 공고 오류 유형 중심으로 받는다.
- **실패:** 오래된 버전의 검수는 409, 미인증·MFA 누락은 차단.
- **보안:** 서버 권한, 입력 검증, 공고·신고 출력 처리.
- **완료 기준:** 일반 사용자 API 우회가 차단되고 중요 변경이 즉시 공개되지 않는다.
- **담당·우선순위:** 백엔드/프론트엔드, P0.
- **시험:** 일반/운영자/MFA 미완료 주체 비교·역할 회수·기준 버전 충돌·중요 변경 재검수·오류 신고 처리·개인 본문 조회 경로 부재·감사 기록.

## F11. TTS·호출 제한·장애 처리

- **UX:** 주요 사용자 화면.
- **선행:** 읽기 대상에 대한 권한, AI 처리 안내·동의, 제한 저장소의 정상 상태.
- **입출력:** 읽기 대상 참조·AI 요청 → 음성·처리 결과·제한 안내.
- **처리:** 접근권한·입력·한도·공유 자원 슬롯 검사 → EC2 로컬 추론(Qwen3-TTS 읽어주기) → 응답 검증 → 사용량·실행 시간 집계.
- **규칙:** 읽어주기는 선택 행동이다. 녹음 시작 시 재생을 중지한다. 재시도도 호출 집계에 포함한다.
- **실패:** 제한 초과는 대기 안내. AI 장애 중 공개 공고 조회와 공식 안내 연결을 유지한다.
- **보안:** 세션·계정·IP·전역 제한, 임의 TTS 프록시 방지, 오류 정보 최소화.
- **완료 기준:** 중복 클릭·세션 재생성·과대 입력으로 제한을 우회하지 못한다.
- **담당·우선순위:** 백엔드/AI·데이터/프론트엔드, P0.
- **시험:** 임의 텍스트/타 사용자 읽기 대상·한국어 발음/문장 일치·60초 타임아웃·중복 요청 ID·LLM/STT/TTS 공유 자원 경계·메모리 부족·IP 헤더 위조·비회원 체험 재생성·재시도 집계·Redis 장애·오류/로그 비밀 노출·외부 AI 추론 통신 없음.
