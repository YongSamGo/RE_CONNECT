# 다시잇다 Engineering Cockpit

`index.html`을 로컬 브라우저에서 직접 연다. CDN, 외부 API, 서버, 패키지 설치가 필요 없다. 스크립트와 근거 데이터는 파일에 포함돼 있다. **Git 커밋은 수행하지 않았다.**

> **main 병합 코드만을 분석한 자료가 아니다.** 최초 분석 당시의 로컬 작업 브랜치 `feat/w11-02-journey-entry`, 커밋 `54d2daa`가 기준이다. 2026-10-25 원격 참조를 갱신해 재확인했다. `origin/main`은 `3bed990`, `origin/develop`은 `cb1559c`다. 분석 커밋에만 있는 커밋은 main 대비 248개, develop 대비 232개이며, 반대로 최신 develop에만 있는 커밋도 7개다. 분석 커밋은 main에 포함되지 않는다. main의 `backend`·`frontend`·`speech`·`infra` 추적 파일은 0개다. main과 분석 커밋 사이에서 이 네 경로의 변경 파일은 541개다. 따라서 이 문서는 main만으로 작성할 수 없었고, 로컬 작업 코드와 당시 시험 결과를 포함한다.

- 분석일: 2026-10-25 (Asia/Seoul)
- 기준 커밋: `54d2daa3f25e6e39d2abf5585786676d09be7941`
- 관찰 브랜치: `feat/w11-02-journey-entry` (로컬 추적 참조 `origin/develop` 대비 232커밋 앞섬)
- 최초 분석 시작 시 작업 트리: clean. 당시 원격 fetch·CI·이슈 상태 조회는 하지 않았다. 가독성 개편 때 원격 main/develop 참조를 fetch해 비교했고, 이번 재확인에서는 develop이 7커밋 더 진행된 것을 확인했다. 원격 CI·이슈 상태는 조회하지 않았다.
- 제품 코드·의존성·설정·DB·배포 환경은 수정하지 않았다. 기존 프론트 빌드는 무시되는 `dist/`·도구 캐시를 만들 수 있다.

## 탐색 방법

왼쪽 여섯 화면을 이동한다. 본문 기본 크기는 17px이며 상단의 **글씨 크게**로 20px로 전환한다. 구조 화면은 **분석 당시 구현 / 목표 운영 연결**을 전환하고 기능을 선택한다. 실행 화면에서는 시나리오와 이전/다음 단계를 선택한다. 기능 목록을 펼치면 의존·남은 작업·완료 조건을 읽을 수 있다.

각 항목의 **코드 근거**는 별도 읽기 창에서 연다. 창에는 기준 커밋의 경로·줄·짧은 발췌와 `git show 54d2daa:<경로>` 명령이 있다. 현재 작업 폴더의 파일을 분석 당시 코드로 오인하지 않도록, 관련 문서의 코드 근거 링크도 HTML의 고정 스냅샷으로 연결한다. Esc 또는 닫기로 본문에 돌아간다. 화면 상단의 **main과 비교한 결과**는 분석 기준과 원격 브랜치의 차이를 설명한다.

가독성 개편에는 Anthropic 공식 [frontend-design 스킬](https://github.com/anthropics/skills/tree/main/skills/frontend-design)을 설치하고 직접 읽어 적용했다. 소스 근거·기능 상태·당시 제품 시험 결과는 유지하고 정보 배치·타이포그래피·상세 공개 방식을 수정했다. 스킬은 사용자 개인 Codex 환경에 설치했으며 저장소의 에이전트 지침이나 제품 의존성을 바꾸지 않았다.

## 범위와 증거 수준

README/AGENTS/CLAUDE, 최신 Plan/03, 개발·진행/통합 게이트, FastAPI 조립·Router·핵심 Service·저장소·계약, React 진입·API 클라이언트·관련 기능, 운영 Compose·CI를 표본 추적했다. 대화/확정, 추천, 자격/초안, 수집 4개 흐름을 재구성했다. 음성 전체 구현·AWS 자원·모든 보안약점의 전수 진단은 범위가 아니다.

**구현 및 검증 완료**는 표시된 코어/선택 시험 범위에 한한다. 기능 전체·실 배포 완료가 아니다. **부분 구현**은 화면/API/운영 연결 중 일부가 남았다는 뜻이다. Mock/Stub은 테스트 대역과 메모리 미리보기에서 사용한다. 미리보기를 실제 AI 성공으로 집계하지 않는다. 목표 화면의 점선은 미연결/운영 미검증을 표시하며 모든 코드가 미구현이라는 뜻은 아니다.

## 갱신

이 파일과 HTML의 기준 커밋을 먼저 확인한 뒤 `git diff <기준 커밋> -- backend frontend speech infra docs/api Plan`으로 영향을 좁힌다. 경로/함수·상태·증거·테스트를 함께 갱신한다. HTML은 정적 스냅샷이며 저장소 변경을 자동 반영하지 않는다.

보안 화면은 보호 자산과 기존 통제의 아키텍처 설명이다. 정식 KISA 합격 판정·취약점 부재 선언이 아니다. 미조치 취약점의 위치·재현 정보를 포함하는 보안 보고서/도구 출력은 저장소 규칙에 따라 `security-reports/`에만 둔다. 이번 산출물에는 비밀값·실개인정보를 포함하지 않았다.

## 산출물 자체 검사

로컬 jsdom으로 6개 화면 전환, As-Is/To-Be·노드 키보드 선택, 데이터 상태, 4개 시나리오의 25단계·이전/다음·오류 분기, 순위 예제, 상태 필터, 보안 필터, 대안 선택, 근거 검색을 확인했다. 모든 소스 앵커와 상대 파일 링크를 대조했다. 실행 오류·외부 리소스 요청은 없었다. 이는 실제 브라우저 렌더링 검증이 아니다. 앱 내 브라우저의 URL 정책이 `file://` 열기를 차단했으므로 실제 표시·모바일·다크 모드의 시각 검증은 미완료다. 사용자가 로컬 Chrome/Edge에서 `index.html`을 직접 열어 확인할 수 있다.

원기획 PDF(17쪽)에서 제품 소개와 12~13쪽 MVP 범위를 텍스트 추출로 확인했다. 통계·외부 정책의 사실 검증이나 PDF 레이아웃 검수는 하지 않았다. PDF/README의 교육·멘토링·지역활동과 현재 취업/봉사 계약의 차이는 **SCOPE·D8**에 남겼다. 범위 축소 승인 여부는 미확인이다.

가독성 개편 후 동일한 6개 화면·25단계·상태 필터·대안 선택을 다시 검사했다. 새 근거 읽기 창의 열기/닫기·Esc·배경 입력 차단, 큰 글씨 전환, main 비교 창, 문서에서 특정 소스 근거로 이동하는 링크도 확인했다. 75개 코드 위치는 현재 checkout이 아닌 **분석 커밋의 Git 객체**와 대조했다. 문서 링크 57개를 검사했고 끊긴 링크·실행 오류·외부 리소스 요청은 없었다. 밝은 테마에서 지정한 본문/보조/강조/경고 색 조합의 대비는 6.37:1 이상이다. 이 수치는 지정 색상에 대한 계산이며 실제 브라우저 배치·모바일·다크 모드·전체 접근성 통과를 의미하지 않는다.
