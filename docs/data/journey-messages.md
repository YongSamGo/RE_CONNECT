# 확인 텍스트와 미승인 경험 초안 (#37)

`POST /api/v1/journeys/{id}/messages`는 `MessageCreate`의 확인 텍스트·전사 참조·기준 리비전과 UUID `Idempotency-Key`를 받는다. CSRF·쿠키 세션·일반 API 한도 뒤 체험 소유권/수명·현재 AI 처리 동의를 검사한다. 모델 주체는 세션과 연결 IP로 만든 `InferenceIdentity`이며 `ControlledLLMAdapter.for_identity()`를 거쳐 실제 호출 한도와 공유 슬롯을 적용한다.

직접 입력은 `transcription_id=null`이고, 전사 ID가 있으면 같은 유효한 자기 체험의 전사인지 검사한다. 다른 체험/타인/없는 전사는404다. 사용자 확인·수정 후 보낸 `text`만 모델 입력에 넣으며 저장 전사 원문은 자동으로 덧붙이지 않는다. 전사 생성 경계와 모델 서버 대기는 [전사 기록](transcriptions.md)을 따른다. 회원 저장본 가져오기는 별도다.

## 근거와 초안

검증한 사용자 턴과 그 체험의 기존 경험만 [근거 제한 생성 서비스](../ai/generation.md)에 전달한다. 알려진 개인정보/직접 지시문 패턴 또는 숨은 문자 때문에 처리할 수 없는 입력은 추론 전에 422로 거절한다. 문자열 필터는 모든 민감정보나 우회를 탐지하는 의미 분석기가 아니다.

원문에 실제로 있는 설명·기간·역량 인용만 경험 초안에 넣는다. 새 경험과 사용자/다음 질문 메시지 ID는 서버가 만든다. 근거에는 해당 사실을 포함한 실제 이번 사용자 메시지 ID를 붙인다. 이전 문맥만으로 사용자가 삭제한 경험을 다시 추가하지 않으며 기존 직접 편집 경험과 희망 조건·거주 정보·자격 등 다른 필드를 모델 출력으로 덮어쓰지 않는다. 기존 확정본은 불변이다. 결과는 미승인 초안이며 확정/저장은 별도다.

이 경로는 원문 기반 경험 추출이다. 전체 프로필의 지역·선호·연령·자격을 자유 문장에서 구조화하는 구현으로 표현하지 않는다. 희망 지역·활동 유형 등은 직접 편집 화면에서 확인할 수 있다. 빠진 최소 항목이 있으면 서버 규칙이 고정 질문 한 문장을 고른다([질문 흐름](../ai/question-flow.md)). 최소 항목이 있으면 `assistant_message=null`, `next_step=review_profile`이다. 자동 확정하거나 자격·역할을 생성하지 않는다.

## 원자 완료와 재전송

추론 예약 뒤에도 초안은 쓰지 않는다. 추출 뒤 재검사하고 최종 단일 Lua 실행에서 세션/동의·체험 세대/수명·기준 리비전·실행권을 다시 검사한다. 성공할 때만 사용자 문맥·응답 본문·프로필 초안/근거·리비전 증가·멱등 결과 참조를 함께 반영한다. JSON 문자열을 그대로 저장해 빈 목록과 null을 Lua 빈 테이블로 바꾸지 않는다.

응답은 체험 수명 메타 해시의 `message_result:<user_message_id>`, 내부 사용자 문맥은 `conversation`에 둔다. 대화 복원 GET이나 영구 대화 저장은 추가하지 않는다. 체험 삭제는 같은 메타 해시와 연결 요청을 지우므로 이 본문도 함께 사라진다. 삭제/만료/철회/동시 수정 뒤 결과는 쓰지 않는다.

동일 키·동일 요청은 저장한 당시 응답을 다시 반환하며 새 추론·리비전 변경·유휴 연장이 없다. 이후 직접 편집이 있어도 과거 멱등 응답을 최신 결과로 바꾸지 않는다. 화면은 응답 리비전을 구분하고 오래된 결과를 최신 편집 위에 적용하면 안 된다. 다른 내용의 키 재사용과 진행 중 같은 키는 409다. 실패/취소한 실행권은 완료에 사용할 수 없으므로 사용자 재시도는 입력을 유지한 채 새 키로 시작한다.

## 한도와 실패

확인 사용자 턴은 최대 64개·합계 UTF-8 12,000바이트이고 각 요청은 2,000자다. 완료 응답은 64KiB 이내다. 성공한 확인 텍스트만 임시 문맥에 쓰며 실패한 본문은 요청 저널에 저장하지 않는다(입력 해시는 익명정보가 아니다).

전체 생성 단계는 60초 제한이며 자동 재시도나 외부 AI 전환이 없다. 모델 호출은 경험 추출 한 번이며 실제 추론 한도를 한 번 소비한다. 질문 선택은 모델을 부르지 않는다. 모델 장애/잘못된 근거는 고정 503, 시간 초과는 `AI_TIMEOUT`이다. 기존 초안·확정본은 유지하고 직접 편집할 수 있다. HTTP 취소/시간 초과만으로 실제 GPU 종료를 증명하지 않으며 종료 확인이 없으면 공유 슬롯을 임의로 풀지 않는다.

`test_journey_messages.py`는 실제 Redis·ASGI HTTP·추론 한도 서비스를 사용하고 모델 런타임만 대역으로 바꾼다. 정상/멱등·리비전·CSRF·근거·직접 편집/확정본 보존·생성 전후 경합·혼잡·시간 초과·문맥 상한·삭제 경험 재생성 방지를 검사한다. 실제 Ollama/EC2 품질·지연·실제 STT 모델/브라우저 전체 대화 여정은 별도 검증이다.

2026-10-18 최종 로컬 회귀: 실제 Redis 7.0.15·PostgreSQL 16.15에서 전체 백엔드 890개 통과·건너뜀 없음(기존 경고 1개). 프론트 계약 15개와 API 타입 대조·빌드도 통과했다. 시험 서버를 종료했으며 원격 CI·실제 모델 품질 검증 완료를 뜻하지 않는다.
