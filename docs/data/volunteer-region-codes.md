# 1365 검수 코드의 지역 변환 (#263)

1365 `actPlace`는 시설명처럼 주소가 아닌 값일 수 있다. 이 문자열에서 지역을 추정하지 않고 목록/상세의 `sidoCd`와 `gugunCd`를 함께 대조한다.

초기 범위는 [#264 평가 자료](https://github.com/YongSamGo/RE_CONNECT/blob/data/w08-08-recommendation-eval/eval/recommendation_review.json)의 `region_codes`에서 검수한 9쌍이다. 해당 자료는 아직 열린 평가 PR의 자료이므로 전국 공인 코드표 전체를 확보한 것으로 보고하지 않는다. 매핑은 이 검수 결과를 재사용한 것이며 실제 공고 원문·최신 모집 상태는 재평가 때 확인해야 한다.

| 시도 코드 | 시군구 코드 | 지역 |
| --- | --- | --- |
| 6110000 | 3030000 | 서울 성동구 |
| 6110000 | 3040000 | 서울 광진구 |
| 6110000 | 3100000 | 서울 노원구 |
| 6410000 | 3780000 | 경기 성남시 |
| 6410000 | 3830000 | 경기 안양시 |
| 6410000 | 3940000 | 경기 고양시 |
| 6410000 | 4020000 | 경기 군포시 |
| 6280000 | 3520000 | 인천 연수구 |
| 6280000 | 3530000 | 인천 남동구 |

코드가 없거나 등록되지 않은 쌍이면 `activity_region=null`, `region_mapping_unknown`으로 유지한다. 목록과 상세가 모두 코드를 주면서 서로 다르면 `region_mapping_conflict`도 남기고 지역을 확정하지 않는다. 인천의 개편 전 중구·동구·서구 코드는 새 구로 자동 변환하지 않는다. 시도만 확인됐다고 도 전체로 넓히지 않는다. 원문 코드 보존은 기존 `unmapped_fields`에 그대로 남겨 운영자가 재확인할 수 있게 한다.

지역 변환에 성공해도 `pending`·필수조건 미검수 표식·빈 태그는 그대로다. 원문 조건·태그를 PATCH로 검수하고 승인하는 절차를 통과해야 추천 대상이 된다. 이 수정만으로 #263 전체나 #65의 실제 평가가 완료된 것은 아니다.

코드를 추가할 때는 출처 코드의 실제 응답과 공식 지역 근거를 대조하고 현재 `Region` 목록에 맞는지 검증한다. 알려지지 않은 코드를 숫자 패턴으로 계산하지 않는다. 참고로 [국가기록원 성동구 기관연혁](https://theme.archives.go.kr/next/organ/viewDetailInfo.do?code=OG0006548&isProvince=Y&mapInfo=mapno10)에서도 성동구의 기관코드 `3030000`을 확인할 수 있다. 다른 코드 쌍의 초기 근거는 위 검수 표본이다.

관련 KISA 원칙은 입력데이터 검증과 비신뢰 외부 자료의 추정 금지다. 코드·시도 불일치와 미확인 행정구역이 잘못된 추천 지역으로 확정되지 않도록 정상/비정상 입력을 정규화 시험에 포함한다.
