## 사전 확인 실행

Python 표준 라이브러리와 인증된 AWS CLI v2를 사용한다. 저장소 루트에서:

```powershell
python -X utf8 tools/aws_readiness.py --region ap-northeast-2 --instance-type g5.xlarge --profile reconnect
```

`sts:GetCallerIdentity`, `ec2:DescribeInstanceTypes`, `ec2:DescribeInstanceTypeOfferings`, `servicequotas:GetServiceQuota`의 읽기 작업만 호출한다. 자원 생성·할당량 요청·과금 설정 변경은 하지 않는다. 프로필은 각자 로컬 설정에 두고 `.env`나 키 파일을 읽어 넘기지 않는다.

출력은 계정 ID·ARN·프로필명·CLI 오류 원문을 제외한 상태와 사양이다. 루트 자격증명이면 중단한다. 조회 실패/권한 부족/CLI 없음은 `unknown`, 승인 할당량 부족·리전 미제공은 `blocked`다. 종료코드 0은 사전 조회 통과, 2는 차단/미확인이다. `launch_ready`는 항상 false다. 제공 리전 조회는 실제 AZ 용량을 보장하지 않으며, 승인 한도는 현재 남은 한도가 아니다. Spot 할당량은 이 도구의 범위 밖이다.
