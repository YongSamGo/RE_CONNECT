  main 이력의 태그에서 Release 실행 → 환경 승인 → 이미지 검사·게시 → manifest/SBOM 확인 →
  digest·출처 증명 검증 순서를 지킨다. 임의 태그나 로컬 빌드로 이를 대체하지 않는다.

5. **실제 앱 시험:** 별도 예산·시간 승인 뒤 DB와 선택한 앱 호스트를 실행한다.
   TLS·migration·HTTPS·로그인·동의·운영자·백업/복구·타이머·전체 여정을 검증한다.
6. **공개 판단:** #97 롤백과 #104 장애 시험, #105 공개 조건을 같은 릴리스 증거로 확인한다.
   실패/미실행 항목은 남겨 두고 완료로 표시하지 않는다. 시험 종료 때 EC2/RDS·잔여 볼륨/IP 비용을 각각 확인한다.

## 최초 GPU 시험 비용안 — 승인 전, 실행 안 함

후보는 서울 Linux Shared On-Demand `g5.xlarge` 1대(4 vCPU, RAM 16,384 MiB,
NVIDIA A10G 1개, API 보고 GPU 메모리 22,888 MiB)다. 제공 AZ가 조회되어도 실제 용량 보장은 아니다.
적용 G/VT 한도 8 vCPU, 조회한 활성 사용 0 vCPU이며 증설 요청 상태는 여전히 `CASE_OPENED`다.

아래는 10/29 AWS Price List API의 공개 단가와 공식 공인 IPv4 단가를 Decimal로 계산했다.
할인·크레딧·환율을 가정하지 않고 USD 세전으로 표시한다. EBS는 월 단가의 730시간 환산 추정이다.
실제 청구 달력·요금 단위와 총 사용량에 따라 달라질 수 있다.

| 항목 | 가정 | 예상 USD |
| --- | --- | ---: |
| GPU 컴퓨팅 | $1.237/h × 최대 2h | 2.474 |
| 임시 공인 IPv4 | $0.005/h × 2h, 할당 유지 시 추가 | 0.010 |
| 암호화 gp3 100GiB | $0.0912/GB-month, 24h 내 정리 가정 | 0.300 |
| 신규 시험 소계 | 위 세 항목 | 2.784 |
| 기타 비용 여유분 | 모델/이미지 전송·로그·ECR·S3·백업 등, 견적 단가가 아닌 예비금 | 5.000 |

**제안 승인 범위:** 위 GPU 1대의 최초 시험에 USD 10 세전, 컴퓨팅 최대 2시간.
기존 EC2·RDS 시작, NAT/ALB 추가, 복원 DB 생성, 추가 GPU·장기 보관은 이 범위에 포함하지 않는다.
gp3 기본 성능만 가정한다. 시험용 새 볼륨의 24시간 내 정리 여부도 실행 전에 정한다.
중지만 하면 EBS는 남아 계속 과금된다. 데이터가 남는 삭제 작업은 대상·보존 필요를 확인한 뒤 처리한다.

현재 보존 자원의 확인 가능한 EBS·RDS 저장소·EIP만으로도 약 **$0.596/24h**가 별도로 든다.
전체 청구액은 아니다. 스냅샷·ECR·로그·S3·기타 리전 자원은 추가될 수 있으며 계정 전체 비용은 집계하지 않았다.
RDS를 다음 앱 시험에서 켠다면 현재 종류의 기본 컴퓨팅 단가는 $0.025/h이고 2h는 $0.050이다.
이는 저장·백업·버스트 크레딧·전송·기타 앱 서버 비용을 포함하지 않으므로 앱 시험 전체 견적으로 쓰지 않는다.

RDS는 **2026-11-04 23:54:38 KST 자동 재시작 예정**으로 조회됐다. 그 전 비용 운영 방침을 정한다.
자동 재시작을 막는 변경이나 반복 중지 자동화는 이번에 하지 않았다. AWS Budgets는 지출 차단 장치가 아니다.
