# 실제 공고 추천 평가 (W08-08 · #65)

> 기준일: 2026-10-27 · 담당: B(AI·데이터) · 스크립트: [eval/check_recommendations.py](../../eval/check_recommendations.py) · 검수 값·기대값: [eval/recommendation_review.json](../../eval/recommendation_review.json) · 코드 기준: develop `83ba4de`

공공 API로 받은 실제 공고를 실제 정규화기·추천 필터·정렬 코드에 넣고, 페르소나 8명([eval/personas](../../eval/personas))의 확정 프로필로 추천을 돌렸다. DB·API를 거치지 않고 모듈을 직접 호출하므로, 공개 승인·버전 재확인 같은 API 경계는 이 평가의 범위가 아니다.

## 표본

| 출처 | 받은 날 | 정규화된 공고 | 비고 |
|---|---|---|---|
| 한국노인인력개발원 노인일자리(senuri) | 10-14, 10-27 | 33건 | 목록 600건 중 수도권 접수 중 공고. 모두 유급 일자리. 목록 API에 검색 조건이 없어 직무로 고르지 못했다 |
| 1365 봉사참여(volunteer) | 10-14, 10-27 | 80건 | 페르소나 희망 지역(성동·광진·노원·성남·안양·고양·군포·남동·연수)을 구 코드로, 일부는 키워드(스마트폰·디지털·돌봄·요양·병원 등)로 골라 받음. 3건은 시니어 대상이 아니라 정규화에서 제외 |

원본은 담당자 연락처가 있을 수 있어 `worker/samples/`(커밋 제외)에만 둔다. 저장소에는 공고 키(`출처:ID`)와 검수 값만 둔다. 다시 돌리려면 [docs/data/sources.md](../data/sources.md)의 오퍼레이션으로 같은 ID를 받아야 하고, 마감된 공고는 결과가 달라질 수 있다.

**검수 값.** 정규화기는 공고의 `skill_tags`·`role_tags`를 비워 두고 1365 공고의 지역을 채우지 못한다(아래 D1·D2). 운영자 검수를 대신해 공고 38건에 역할 사전의 확인된 태그를 붙이고, 1365 구 코드 9개를 지역으로 바꿨다. 추천 후보에 오른 공고 7건은 원문을 읽고 연령·자격증 조건을 구조화했다(`requirements`, 연령 기준일은 검수일 2026-10-27). 태그는 제목만 보고 붙였으며 **사람 검토가 필요하다.** 활동 유형이 미확인인 P03·P06·P08은 재질문에 "둘 다"라고 답했다고 가정했다(`confirmations`).

- 추천된 5건 모두 근거 경험 ID가 프로필에 있고, 근거 태그가 공고 태그와 실제로 겹친다. 무근거 연결과 지역·유급 조건 위반은 없었다.
- 조건을 구조화하기 전에는 7건이 추천됐고, 그중 2건(나사렛국제병원 → P07, 일산병원 → P08)은 원문을 읽으면 연령 미달이다. 두 건은 "확인 필요"로 표시되긴 하지만 명백한 미충족이다(D5).
- 기대값에 적은 "나오면 안 되는 공고"(미화·대학생 한정·관련 없는 행사 등 22건)는 하나도 추천되지 않았다.
- 조건을 구조화하지 않은 공고의 자격은 `unknown`(확인 필요)이다. 정규화기가 모든 공고에 "필수조건 미검수" 조건을 넣기 때문이며, 미충족을 충족으로 오판하지 않으려는 의도한 동작이다.
- 성공 확률이나 점수는 응답에 나오지 않는다. 내부 점수는 정렬에만 쓴다.

## 다시 돌리기

```bash
# 원본 샘플 받기 (.env의 DATA_GO_KR_SERVICE_KEY 필요, 저장 위치 worker/samples/)
python worker/tools/fetch_source_samples.py volunteer --operation getVltrAreaList --param schSido=6110000 --param schSign1=3030000
python worker/tools/fetch_source_samples.py volunteer --operation getVltrPartcptnItem --param progrmRegistNo=<번호>
python worker/tools/fetch_source_samples.py senuri --operation getJobList --param numOfRows=100
python worker/tools/fetch_source_samples.py senuri --operation getJobInfo --param id=<jobId>

# 평가 (백엔드 가상환경)
backend/.venv/bin/python -I eval/check_recommendations.py
backend/.venv/bin/python -I eval/check_recommendations.py --list-postings   # 검수 값 작성용 공고 목록
```

1365 `schSign1`은 구 코드다(성동 3030000, 광진 3040000, 노원 3100000, 성남 3780000, 안양 3830000, 고양 3940000, 군포 4020000, 연수 3520000, 남동 3530000). 기관 이름으로 대조해 확인한 값만 `region_codes`에 넣었다.

기대값과 다르거나 추천 근거가 프로필에 없으면 종료 코드 1이다. 원인을 위 결함 번호로 기록한 항목은 `known_missing`에 두고, 고쳐지면 스크립트가 알려 준다.
