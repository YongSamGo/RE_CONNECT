# 경험 추출 EC2 CPU 측정 (2026-10-28)

> 담당: B(AI·데이터) · 관련 이슈: #30(W04-03), #34(W04-07) · 대상 코드: `GroundedGenerationService.extract_experiences`, 프롬프트 `grounded-v1` → `grounded-v2`
>
> [2026-10-22 예비 측정](extraction-eval-2026-10-22.md) §5의 재측정이다. GPU 할당량 승인 전이라 **CPU 인스턴스에서 측정했다.** GPU 지연과 품질은 승인 후 다시 잰다.

## 1. 환경

| 항목 | 값 |
|---|---|
| 장비 | EC2 `m7i.xlarge`(4 vCPU, 16GiB), 서울 리전, Ubuntu 24.04. GPU 없음 |
| 모델·런타임 | `qwen3:4b` Q4_K_M(매니페스트 digest `359d7dd4…` 일치), Ollama 0.40.3 CPU 라이브러리만, `127.0.0.1`·`OLLAMA_NO_CLOUD=1` |
| 요청 | 실제 `OllamaLLMAdapter` → `GroundedGenerationService.extract_experiences`. `think=false`, `num_ctx=16384`, `num_predict=2048`, `temperature=0`. 시간 측정을 위해 Adapter 제한만 600초로 늘림(서비스 기본은 60초) |
| 입력 | `eval/personas/P01~P08.json`의 `interview`(가상 인물) |
| 메모리 | Ollama 실행 프로세스(llama-server) RSS 약 5.9GiB |

## 2. 결과

| 지표 | `grounded-v1` (n=8, 1회) | `grounded-v2` + 인용 단위 폐기 (n=16, 2회) |
|---|---|---|
| 서비스 검사 통과 | 3/8 | **16/16** |
| 60초 안에 끝남 | 1/8 (41~151초) | 15/16 (20~44초, 첫 요청만 모델 적재 포함 62초) |
| 경험이 아닌 턴을 경험으로 추출 | 있음(P04 "급여 받는 일을 찾아요" 등) | **0개** |
| 2회 실행 결과 일치 | - | 16/16 동일 |

v1 실패 5건은 모두 기술 인용을 다른 턴에서 가져와 결과 전체가 `LLMInvalidOutputError`가 된 경우였다(P01~P04·P08). 지연이 크게 줄어든 것은 v2가 더 짧은 구절을 인용해 출력 토큰이 줄었기 때문으로 보인다.

## 3. 이번 변경

- **인용 단위 폐기:** 경험 설명이 원문에 없거나 기존 ID가 맞지 않으면 지금처럼 결과 전체를 거절한다. 기간·기술 인용이 설명과 다른 턴이거나 원문에 없으면 **그 인용만 버리고** 경험은 남긴다. 중복 기술은 하나로 합친다.
- **프롬프트 `grounded-v2`:** 경험이 아닌 것의 목록, 같은 턴의 짧은 구절만 인용, 예시 1개(10-22 문서 §3의 실험안).

## 4. 남은 문제

| 문제 | 사례 | 영향 |
|---|---|---|
| 설명에 문장 전체를 인용 | P01·P02·P05·P06·P08 | 화면의 경험 설명이 길다. 사용자 편집으로 보완 가능 |
| 두 번째 경험을 놓침 | P01 방과후 독서 지도, P02 관리 업무, P08 대출 상담(기술로만 들어감) | 추천 근거가 줄어든다 |
| 기술이 비거나 일반어 | P01·P02·P04 비어 있음, P06 "택시", P03 "동네 부녀회장" | 추천의 기술 태그 일치(D3)에 불리 |
| 자격증 구절을 기술로 인용 | P07 "요양보호사 자격증" | 자격 보유와 업무 경험이 섞인다. 사용자 확인 단계에서 걸러야 함 |

P04의 기술(세금계산서 발행·월말 결산)이 다음 턴에 있어 버려진 것처럼, 인용 단위 폐기는 실패를 막는 대신 정보를 잃는다. 다음 개선은 업무 내용 턴을 별도 경험으로 뽑게 하거나, 같은 경험을 설명하는 인접 턴을 묶는 방식을 비교한다.

## 5. CPU 운영 판단

경험 추출만 보면 v2는 CPU에서도 대부분 60초 안에 끝난다. 다만 대화 응답·지원서 생성과 TTS(같은 장비에서 짧은 문장도 22~45초, 244자는 55초 제한 초과)를 함께 고려하면 GPU가 필요하다는 판단은 그대로다. 음성 측정은 #34에 기록한다.

원시 로그는 `security-reports/ec2-cpu-baseline/`에 있다(커밋하지 않음).
