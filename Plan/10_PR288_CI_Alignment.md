# PR 288 최신 이용 흐름과 CI 정리

기준 커밋: 7e594669. 기준일: 2026-10-29.

## 확정한 범위

- 시작 안내에서 시작하기를 누르면 게시된 AI 안내를 팝업으로 보여준다. 동의를 선택하면 바로 대화를 시작한다.
- 대화와 프로필은 현재의 간결한 화면, 필드별 수정, 답변 확인 창을 유지한다.
- 회원 기능은 나의 정보로 모은다. 프로필 저장과 수정, 로그아웃과 탈퇴를 제공한다.
- 지원서는 현재 체험에서 생성하고 수정, 검토한 뒤 공식 신청처로 이동한다. 회원 지원서 저장 목록과 복구는 제공하지 않는다.
- 공고 상세는 자동 조회한다. 별도 불러오기나 원문 URL 표시, 개발용 부가 정보는 되살리지 않는다.
- 큰 글씨에서는 내용에 따라 홈 박스 높이가 늘어난다. 글자와 버튼이 겹치거나 잘리지 않아야 한다. 사용자가 2026-10-29에 선택했다.
- 공고의 공격 지시문 필터를 유지한다. 모델에 전달하는 공고 식별 정보는 복구하고 정상 원문과 공격 입력을 각각 검증한다.

## 실행 순서

1. 누락된 공고 ID와 버전을 생성 입력에 복구한다. 필터링한 공고 본문과 확정 개인 사실은 분리한다.
2. 예전 수동 조회, 이전 버튼 문구, 삭제된 미리보기와 저장 기능을 기대하는 테스트를 최신 이용 흐름에 맞춘다.
3. 자동 조회, 오류 복구, 입력 보존, 동의, 계정 소유권, 중복 방지, 외부 링크 검증을 계속 검사한다.
4. 접근성 검사에서 비동기 작업과 타임아웃을 정리한다. 브라우저 검사는 실제 시작 팝업과 현재 이동을 따라간다.
5. 관련 테스트와 정적 검사 후 전체 프론트, 브라우저 및 CI를 확인한다. 실제 화면도 브라우저에서 확인한다.
6. 같은 PR에 커밋하고 검증 결과를 갱신한다. CI가 통과하기 전에는 병합 가능하다고 보고하지 않는다.

## 변경 전 증거

- 프론트 569개 중 202개 실패. 27개 파일에 걸쳐 예전 UI 기대, 비동기 조회, 접근성 실행 오류가 포함됨.
- 브라우저 15개 중 10개 실패. 예전 시작 화면 기대 8개, 큰 글씨 고정 높이 1개, 뒤로가기 링크 역할 1개.
- 통합 315개 중 5개 실패. 공고 식별 정보 누락 2개와 공격 지시문 필터 기대 차이 3개.
- 상세 도구 출력은 `security-reports/ci-288/`에만 보관하며 커밋하지 않는다.

## 실행 결과

- 삭제된 미리보기와 회원 지원서 보관 테스트는 현재 주소로의 전환과 쓰기 요청 부재 검사로 바꿨다. 프로필 저장의 동의, 교체 확인, 중복 방지와 실패 복구 검사는 유지했다.
- 공고 조회는 자동 진입, 검색은 결과 화면 전환을 기준으로 검사한다. 오류 복구, 소유권 변경, 늦은 응답과 비신뢰 문자열 검사를 유지했다.
- 브라우저에서 개발 모드의 대화 초기 조회가 취소 후 재시작하지 않는 문제를 발견해 수정했다. StrictMode 회귀 검사도 추가했다.
- 불확실한 답변 전송과 지원서 승인에는 오류 상태에서만 복구 행동을 제공한다. 입력을 버리는 복구는 명시적으로 확인한다.
- 320px 프로필 제목이 수정 버튼에 밀려 여러 줄로 나뉘는 문제를 실제 캡처로 확인해 세로 배치로 수정했다.
- 로컬 프론트 전체 512개, API 계약 16개, 생성 로직 139개, 실제 Chromium 브라우저 16개 검사가 통과했다. 추천 화면 이탈 후 프로필 제거 검사 1개를 추가해 별도로 재확인한다.
- 브라우저 검사는 가상 API 자료로 수행했다. 실제 AI, 카카오 인증과 운영 DB 왕복의 증거가 아니다. PostgreSQL과 Redis 통합은 새 CI에서 확인한다.
- 타입 검사, 린트, API 스키마, 문구 검사와 배포 빌드가 통과했다. 빌드의 기존 청크 크기 경고는 남아 있다.
- PR 288의 최신 CI 결과는 push 이후 확인한다. 통과 전에는 병합 완료로 기록하지 않는다.
